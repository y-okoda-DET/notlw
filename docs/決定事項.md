- 確認用の静止画（書き出した版から、網点ありで）でユーザーがOKを出してから、Windows版を作る。
- 確認のやり方は docs/手順_確認.md に一本化し、`blender/check.sh` で回す（試作18、ユーザーと合意。ルールを増やすより、機械で止まる形にして覚える量を減らす）。

- ユーザーからの画面録画は不要。スクリーンショットのファイル名（場面・位置・向き・時刻）から同じ画をこちらで再現する。
