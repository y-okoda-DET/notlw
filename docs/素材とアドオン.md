## アドオン

- いまは使っていない。木（スギ）は Sapling Tree Gen を使わず、blender/trees.py で自前に組んだ（枝打ちされた幹、上半分だけの細い樹冠、房になった葉、木ごとの高さ・太さ・傾き・梢の折れ。Sapling の葉は平たい板で、スギの房の形を出しにくいため）。
- 作業環境の接続：dl.polyhaven.org・extensions.blender.org はつながる。api.polyhaven.com・ambientcg.com・www.ambientcg.com・acg-download.struffelproductions.com・acg-media.struffelproductions.com も、ユーザーが許可に足して、つながるようになった（2026-10-31）。
- BudouX（Google、Apache-2.0）：台詞の文節の切れ目を求める道具。godot/lang/extract.py でだけ使い、配布物には入らない（2026-11-02）。
- assets/tex/lived_photo_lift.jpg（2026-11-07、試作73）：ユーザーの写真 lived_photo.jpg（猟仲間の集合写真、ユーザー提供 2026-11-04）を明るさだけ起こした物（Claude、PIL）。夕方の廊下の刷りで中身が読めなかったため。
- Mixamo の動き（Adobe、2026-11-09 ユーザー提供）：Walking、Walking Up The Stairs、Descending Stairs、Left Turn、Right Turn（FBX、Without Skin、30fps）。Adobe の規約では、ゲームに組み込んで配るのは無料で可（商用も可）。動きのファイルそのものを単体で配ったり再配布したりはしない。そのため元の FBX はリポジトリに入れず /mnt/project-files/段階2/mixamo/ に置き、blender/export_walk.py が4人の骨に焼き直した物（godot/assets/dusk/<k>_walk.glb、ビルドで作る）だけを pck に入れる。
- 仮の音（ステップ E、2026-11-12）：godot/sound/*.wav は godot/sound/make_sounds.py が numpy・scipy の数式だけで作った物（雨、ノック、ラジオの雑音と声のような唸り、テープの回る音、発電機と止まる音、車、車のドア、玄関の扉）。録音も外の素材も使っていないので、ライセンスの条件はない（作った物はこの作品の物）。ノック（knock*.wav）とラジオの雑音（radio_static.wav）は、ユーザーの収録（/mnt/project-files/音/収録_2026-11-12/、ユーザー提供 2026-11-12）を godot/sound/cut_recordings.py で切り出した物に替えた（ラジオは実在の放送が聞こえない所だけ）。2026-11-13、雨（dragon-studio gentle-rain-01）・発電機（本命、freesound の generator）・雷（thunder_02、雷雨）・足音（木足音２、きしみ足音２、きしみ足音）・停電（ブレーカー落ちの「パチッ」）は、下の表の素材から godot/sound/cut_materials.py で切り出した物に替えた（数式の雨と発電機は使わない）。2026-11-13、ラジオは3局（音楽＝ユーザーが DAW で作った「claudehop」、外国語＝speechgen の韓国語の天気予報、ニュース＝ユーザーのリテイク待ちで数式の唸りを仮に）を、/mnt/project-files/音/ラジオ加工_2026-11-13/ から godot/sound/cut_radio.py で局ごとの繰り返しにした。ダイヤルの擦れと刻みは数式。本番の音は段階4（サウンドクリエイター）で差し替える。鳴らし方は godot/scripts/sound.gd。
