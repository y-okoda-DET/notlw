# インタビュー場面の画（2026-11-15、スレッド「インタビュー場面の画を詰める」。Claude の案、ユーザーの返事待ち）

仕掛け（docs/資料/インタビュー場面の仕掛け_2026-11-15.md）の「まだ決めていないこと」のうち、画の3つを1案に決めた。案の画は /mnt/project-files/インタビュー/画の案_1回目/（Blender で仮に建てた部屋に、riso2.gdshader の夕方の刷り（look=0）と同じ式を Python で当てた物。ゲームから撮った画ではない）。

## 1. 部屋：澪の実家の客間、障子の昼（陰翳）
- **場所は澪の実家の和室の客間**。聞き手が訪ねてきて、澪が玄関を開けて通した。序章で警察に開けた扉に続いて、澪が自分で開けた二つ目の扉になる。最後に聞き手が「礼を言って帰る」のも、ここなら自然。
- **光は障子一面の昼の光だけ**。部屋の照明はつけない。障子は刷りの中で「紙の白そのもの」になる。作中で初めて、紙の白が光として画面の大半を占める（夜は青緑、夕方は橙だった）。家の夜と夕方の刷りの式はそのまま（全編に同じ処理をかける、企画書）。昼は夕方の刷り（look=0）に、光の量で白を多くするだけ。
- 障子の外に庭木を置き、葉の影を障子に落とす（案の画ではまだ弱くて刷りに出ていない。本番で詰める）。動くのは葉の影だけ。
- 3回目に部屋が「平たくなる」とき、障子の部屋はもともと紙と桟の平面なので、陰影が抜けただけで背景画になる。昼の部屋を障子にした一番の理由はここ。

## 2. 聞き手の見せ方（証言 一・二）：顔は画の外、手とテープだけ
- 澪は座卓をはさんで座っている（目の高さ約 0.8m）。聞き手は障子を背にして座るので、逆光で体は青の網点の影になる。**顔は画面の上の端で切れて、1・2回目は一度も映らない**。プレイヤーが見下ろせるのは机の上：聞き手の両手、桐生のテープ（VHS、手書きのラベル）、帳面、録音機、湯呑み2つ。
- 会話の決闘の主役は手。話の間、右手の指がテープの上で動く（回す、置き直す、ラベルを撫でる）。手元に寄った画（案の画 2）を、答えを組む間の基本の画にする。
- 橙の版は湯呑みのお茶だけに残す（昼の部屋で暖かい物はそれだけ）。
- **3回目に部屋が平たくなった瞬間、初めて聞き手の顔が見える**（立ち絵）。顔を見せないまま来たので、ノベルゲームの型に入ったことが、顔が出ることそのものでわかる。

## 3. 平たくなった画面（証言 三）：ノベルゲームの配置を、同じ紙とインクで
- 借りるのは配置だけ（立ち絵が中央、画面の下に文章の窓、名前の札、待ちの▼、隅の「ロード」）。窓の作りは刷りの紙（角丸、半透明、グラデーションにしない。取り決め4）。
- **背景**：同じ部屋の同じ角度から、光と影を抜いて、物の色だけの平らな網点にする（Godot では光を受けない材質に切り替える。案の画 3）。
- **立ち絵**：画像生成で描く。同じ2色の刷り。紙から切り抜いた形で、白い切り代と、平らな青の網点の影がつく。表情は4枚（微笑み、目を細める、真顔＝手が止まる、目を伏せてテープを置く）。プロンプトは /mnt/project-files/インタビュー/画像生成_1回目.md。
- **文章の窓**：画面の下の幅いっぱいに、書き起こしの紙を一枚重ねる（角は四角、影は平らな青の網点）。名前の札は切った紙片を貼った形。字は今の決まりのまま（BIZ UD明朝 Bold 32px、名前は小さく、札はしっぽり明朝）。ただし紙の上なので、字は白抜きでなく青緑のインクで刷る。消した答えは今の「選ばなかった言葉」と同じ二重線で窓の中に積もる。
- **ロードの一覧**：書き起こしの一覧の形。番号、小さい背景の刷り、時刻（ドットゴシック16：録音機の時刻なので機械の文字）、消した答えの頭。どの記録も同じ秒（例 01:14:08）。最後の枠に「上書きしますか？」。
- **聞き手が何者か（案）**：本を書くためにこの件を取材しているノンフィクションの書き手（50代の女性）。ゲームの画面の文字は全部「数か月後のインタビューの書き起こし」なので、その書き起こしを作っているのがこの人、ということになる。ノベルゲームの文章の窓が書き起こしの紙なのも、この人の原稿だから。名前の札はいまは「聞き手」。名前を出すかは台本のときに決める。
