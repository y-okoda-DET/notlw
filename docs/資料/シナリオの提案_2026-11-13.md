# シナリオの提案：真琴と大河、仕掛けと画（2026-11-13、「シナリオを確認して質問に答える」スレッド。**ユーザーの返事待ち**）

ユーザー「（真琴と大河）提案して」「筋が通ってる上で面白く、ゲームとして新鮮さがあるか、いい仕掛け、いいビジュアルが見られるかを優先した提案をください」。
企画書の「仕掛けは三つに絞る（扉、テープ、証言）」は守る。どれも三つのどれかを太くする物で、四つ目は足さない。

## 1. 真琴：看護の記録をつける人にする（証言を太くする）
- 真琴は0時から、絵コンテの裏に時刻と症状を書きつける（「0:10 大河さん 発汗 顔色不良」「1:30 錯乱 頭痛」「3:20 自分 頭痛」）。看護学科の習慣で、『遊星からの物体X』の血液検査にあたる、彼女なりの「誰が感染しているか」の確かめ方。
- 第3章で、澪（プレイヤー）は時計を読み上げ、手元を照らして、その記録を手伝う。
- 4時、真琴が一酸化炭素だと気づく根拠は、この記録（症状が下の階から順に出ている）。最後の行は夏希のこと：「4:02 夏希さん 頭部 新しい傷 二か所」。真琴は見たとおりに書く人だった。
- 第6章で、片づける物が一つ増える。澪はその一行（か、その一枚）を破る。自分が手伝って書かせた、死んだ後輩の丁寧な字を。
- 「言えなかったこと」：1時ごろ、真琴は扉の番の澪に毛布とお菓子を持ってきて、一度だけ聞く。「去年、本当は何があったんですか」。選択肢はどれもはぐらかす。真琴「じゃあ、朝になったら教えてください」。桐生の「朝になったら必ず入れる」と同じ、守られない朝の約束になる。
- 画：2色刷りの中の手書きの表。記録の3つの形（テープ＝機械、記録＝手書き、証言＝声）がそろう。

## 2. 大河：本当の言葉を嘘として言わせる（扉を太くする）
- 0時、地下に入った大河が扉越しに澪にだけ言う。「陽太のこと、俺のせいだよな」。大河は一年間、自分の口論が陽太を殺したと思っている。ノックのことを言えば、彼は楽になる。
- 選択肢はどれも慰め（「大河くんのせいじゃないよ」）。それは本当のことで、澪はなぜ本当なのかを知っているが、理由は言わない。本当の言葉を、黙るために使う。
- 1時半の「転化」は、うめき声だけでなく、地下の扉を内側から叩く音にする（一酸化炭素で錯乱して出ようとしている）。ろれつの回らない「開けろ」。この家で扉を叩いて開けてもらえなかった3人目で、今度は家の中から。
- 確認が要ること：地下への扉は廊下の奥（前室つき）で、玄関の澪から音が届く距離か（部屋のデータで確かめる）。

## 3. 第3章を「扉の番」の章にする（ゲームとしての新しさ）
- 23時から3時半まで、プレイヤーは玄関の扉の前から動かない（動けるが、澪は座っている）。できるのは見ることと聞くことだけ。家の出来事は、壁越しの音と、扉の前に来る人として届く：真琴（1時、毛布と質問）、地下の音（1時半）、桐生（2時、「ついてきてくれ」）。
- 歩くゲームの真ん中で、歩くことを取り上げる。全員が澪に何かを頼みに来て、澪は一つも引き受けない。
- 一晩で一度だけ、扉を離れる（0時前、真琴に呼ばれて大河の傷を見に行く）。プレイヤーが自分の足で離れたその数分に、夏希の二度目のノックがある。戻ると、土間が少し余計に濡れている。気づかなくてよい。第11章のテープで知る。
- 作る場所は玄関まわりだけで済む（第3章の場面が少なくなる）。隙間風（決定済み）をここでしっかり描ける。
- 気をつけること：玄関から廊下を見通す画は「一点透視の廊下」になるので使わない。澪は扉に背をつけて横向きに座り、画は土間・扉・細い窓・毛布の近い画で作る。

## 4. 赤は「撮っている」ときだけ（画の決まり）
- 2色刷りの外に、赤を一つだけ持つ。使うのは、定点カメラの録画ランプ、第4章の照準（頭に合うと赤）、桐生のファインダーの録画の印、最後のデッキの録画ボタン。ほかには一切使わない。血も赤くしない（刷りの青のまま）。
- 赤＝機械の目が見ている印、という決まりになり、最後のカット（録画ボタンの上で止まる指）が、説明なしで読める。
- いまの版でも録画ランプと照準は赤（決定事項 2026-11-11、11-12）。決まりとして書き、ほかに赤が出ていないかを確かめるだけ。確かめていないこと：いまの画に、ほかの赤があるかどうか。

## 5. 嘘をつくと版がずれる（後半の割り込みの入り方）
- 後半のインタビューで澪が嘘を答えた瞬間、刷りの2つの版（青と青緑）が少しずれ、ずれた隙間から割り込みの場面（桐生の2時、陽太の夜）が始まる。3回目（夏希）ではずれたまま戻り、割り込みは来ない。第11章でテープのトラッキングを合わせると、版も合う。
- ラジオの目盛り（音）、テープのトラッキング（画と音）、版（語りそのもの）。「合わせる」が3つそろう。幻覚ではなく、紙の刷りの出来事なので、「幻覚を使わない」に反しない。
- 使うのは後半の3回だけ。それより前では一度もずらさない。

## 6. 陽太が玄関を離れる理由（残っていた弱い所）
- 扉の向こうの笑い声を聞いて、陽太は「やり返されてる」と思う。笑って、裏の窓へ回る。今度は自分が三度目を仕掛けるつもりで。裏の斜面で、もう一度滑る。
- 偶然ではなく、いたずら好きという彼の台本が死因になる（桐生と同じ直し方）。3時半に夏希が裏の窓から入ってくることとも重なる。

## 直さないと決めた物
- 3時半の夏希に「放送はここじゃなかった」を言わせる案は出さない。テープの5行は第4章と同じ秒で作ってあり、足すと最後の「一人じゃ、無理だった」が薄まる。知らせようとした跡は、二度目のノックとスマホの下書きで足りる。
