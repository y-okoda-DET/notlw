# 手順：確認

## 原則
- 自分が直したところを、直ったと見える角度で撮らない。人間が見る角度で撮る。
- 前提（どちらが手のひらか、など）を疑う。数値が合格でも、画が人間に見えなければ不合格。
- 確認していないことは「確認していない」と書く。

## 速い回し方（1回 10〜15分）
- 人物だけ直したとき：`SKIP_LM=1 python3 export_godot.py`（光の焼き込みと env.glb を飛ばす）→ Godot の取り込み → 確認画。
- 確認画は書き出しを待たずにプロジェクトから撮れる：
  `close.py <scene> <名前> <bx,by,bz> <距離> <方位,...> <時刻,...> [高さ] [確認用の光]`
  1コマ約20秒（`--at=` でその時刻から始め、12コマで終わる）。
- 暗い場面の手元は確認用の光 0.12〜0.25（刷りの明るさは 1.0 になる）。本番の光ではないことを明記する。
- Windows 版は、ユーザーが静止画で OK を出してから作る。

## 必ず撮る角度
| 項目 | 角度 | 不合格の例 |
|---|---|---|
| 顔 | 正面・見上げ・真横・後ろから回り込み | 段差、裂け目、色の違い |
| 首 | 真横・斜め後ろ（反応の前・最中・後） | 襟の上に首が乗る、ねじれ |
| 手と持ち物 | 手のひら側・甲側・本人の目 | 甲に乗る、指が物を貫通、指が画面にかかる |
| 手と面（扉・板） | 横・上 | 指が面を抜ける |

## こちらで見えないもの（ユーザーのPCでしか見えない。ユーザーからの録画は不要）
- GPU がないので SDFGI の返し光（逆光の白飛びなど）。夕方は 7/8 太陽、9/0 戸口の空、[ ] 照明（フレネル）で実機で調整できる。
