# 第6章「消えずに残る物」の案（2026-11-25、レビュー 5-4 の続き。ユーザーの返事待ち）

手順ごとに一つ、片づけた手が残してしまう物を決め、あとの章で一度だけ人の口か画で戻す。案内の文では言わない。

| 手順 | 残る物 | どこで戻るか |
|---|---|---|
| 三脚を拭く | 右の袖口に、拭いた血が茶色く残る（洗面所で洗っても薄く残る） | 証言 一。聞き手が手元を見る寄りの画に袖口が入る。誰も触れない |
| 三脚をしまう | 袋のファスナーが閉じきらず、脚の先が一本のぞく | 証言 二。聞き手が出す警察の写真の端に、階段下の袋 |
| テープを入れ替える | 一本目のラベルの「定点」の字に、澪の指の血がにじむ | 第11章。聞き手がテープを出すとき、札が一瞬映る |
| 電池を戻す | 予備の電池に澪の字で「予備」（いまの設計どおり） | 証言 二。聞き手「電池に、あなたの字が」 |
| 下書きを消す | 消しきれなかった「放送、ここじゃな」（いまの設計どおり） | 証言 三の嘘の選択肢（いまのまま） |
| スマホを戻す | 充電したので、電池が 0% でなく 6% | 証言 三。聞き手「夏希さんの電話、電池が残っていたそうです」 |
| 毛布をかけ直す | 真琴は肩まで、澪は顔までかける | 第11章の夜明けの定点の画。かかり方だけが変わる |
| 箱を戻す | ほこりの上に、置き直した四角い跡が二重に | 第8章の朝、監督の章の画の端 |
