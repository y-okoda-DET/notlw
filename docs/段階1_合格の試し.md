# 段階1の合格の試し（2026-11-03、試作43）

合格：初見の人が15〜20分通して遊び、置いたカメラ・扉の前に立つ体験・聞き取れないラジオの三つが記憶に残る（企画書のロードマップ）。

## 遊んでもらう前に
「撮影合宿に来た大学生の話です。操作は画面の上に出ます。終わったら少し質問させてください」とだけ言う。中身やねらいは話さない。詰まっても口を出さず、詰まった場所と時間をメモする。

## 遊び終わってすぐに聞くこと
1. どんな話でしたか。誰かに説明するつもりで、一言で。
2. 一番覚えている場面はどこですか。
3. 一番覚えている物は何ですか。
4. 定点カメラを置いたとき、どこに置いて、何を撮ろうとしていましたか。
5. 扉の前で、澪は何をしていましたか。あなたは何をしていましたか。
6. 扉の前にいたとき、どんな気持ちでしたか。
7. ラジオで聞き取れなかったのは何でしたか。それを聞いてどう思いましたか。
8. 登場人物を何人覚えていますか。名前と、どんな人だったか。
9. 澪と夏希はどういう関係だと思いましたか。
10. 迷った所、分かりにくかった所、退屈だった所は。
11. 続きがあったら遊びたいですか。なぜ。

## 見る人のメモ
- 通しの時間／カメラのパズルで詰まった時間／ラジオで千十七に合わせるまでの時間
- 扉の前で、扉を調べたか（E）、W で前に出ようとしたか

## 合格の目安
4・5・7 がこちらから言わなくても具体的に出てくれば合格。1 と 3 に自分から出てくれば、なおよし。
