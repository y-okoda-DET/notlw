01　方向性

2色のリソグラフ刷り

映画サークルの手刷り冊子のように、全編を2色で刷る。網点の粒は毎コマ入れ替わり、版はわずかにずれ動く。画面全体にかける処理なので、実時間の描画でも同じ画になる。

刷りの決まり

  • 三段の刷り：紙の白／青／重ね刷りの青緑。中間調は刷らず紙を残し、暗部はベタの青で形を刷る。
  • 刷りの明るさ：夜 1.8、夕方 1.3。網点は画面全体で同じ細かさ。
  • 全編に同じ処理をかける。証言パートだけ刷り分ける案は採らない。
  • 夜は青の中にオレンジの光だまり、夕方はオレンジの中に青の影。2色の対比で時間帯を見せる。
  • 照り返しは VoxelGI（夕方・夜とも）。カメラは18コマが標準。

使わない記号

作品の中に理由がない限り、次のものはすべて使わない。

  • PS1風、低解像度と粒子ノイズ、隠すための低解像度
  • 懐中電灯一灯、一点透視の廊下
  • 彩度落とし（「暗い映像にノイズを乗せた」画）

合格の基準

A.MAZE Awards にノミネートされる水準。「ホラーゲームとして成立している」は不合格。この画を見ただけで、どの作品かわかることが合格ライン。

UI

UIはすべて作品世界の中の物にする（章カード＝インタビューの質問、手書きの絵コンテ、メモ、ファインダー）。中央寄せの角丸ボタン、グラデーション、汎用サンセリフ、「スタート／設定」の定型配置、カード型レイアウトは使わない。

04　舞台

間取りの意図

NOTLD から借りたもの

  • 家の中心に、上りと下りの階段を重ねる：2階への階段の真下に地下への階段。「上に逃げるか、地下にこもるか」の対立を家の真ん中に形として置く（大河と真琴の対立）。
  • 左右に部屋が分かれる：西に居間（上映会、薪ストーブ、鹿の剥製）と食堂、東に書斎（和室、剥製、机）と台所。
  • 台所の脇に食品庫と勝手口：工具箱に金槌と釘（板打ちの材料）。裏ポーチに薪と灯油。
  • 部屋の雰囲気：腰壁、窓を塞ぐ不揃いの板、曇りガラスの室内扉、額の絵。
  • 非常放送はラジオだけ（テレビは置かない）。

日本の別荘として変えたもの

  • 正面玄関が物語の要：土間、上がり框の段差、細い窓のある扉。23時の扉の場面の舞台。外にポーチ（夏希が立つ）、南東の私道に夏希の車。
  • 玄関の真上は2階の階段ホール：南の窓からポーチと車がいちばんよく見える。
  • 暖炉→薪ストーブ：煙突は居間の西の外壁沿い。
  • 敷地は東へ下る斜面：地下室の東の壁だけが地上に出る。
  • 地下の小窓＝排気口：第2章で外から板で塞ぐと排気も塞がり、第3章で発電機を動かすと地下に排気がこもる（大河の死因）。
  • 閂の扉：地下の階段の下、内側から閉める。トイレは1階の廊下の奥だけ。
  • 2階：寝室1〜3、洗面・浴室、吹抜け。「階段を上り切った所」は NOTLD の引用に使える。

05　演技

持ち方・押し方の参考写真

手の形の正解は、言葉の条件ではなく写真から取る。新しい持ち方・動作が出てきたら、同じように正面・横・本人の目の写真を撮る。

スマホ（桐生・夏希）

縦長のまま手のひらに乗せる。指はほぼまっすぐ背面に並び、指先が向こうの縁から少しのぞく。親指は手前の長い辺に沿う。

扉（大河）

体ごと前に傾け、目の高さで両手を扉に。指はまっすぐ上、肩幅より外、腕はほぼ伸ばす。頭は肩越しに廊下へ。

レフ板（真琴）

手のひらを内側に向けて左右の縁を持ち、縁を親指と人差し指で挟む。肘は下、脇を閉じる。

05　演技と小道具

動き・カメラ・小道具の指針

演技

  • Mouthwashing 寄り：動きは最小限。待機中はゆったり、出来事は突然に。
  • 急な局面は、アニメーションの速さではなく、ポーズの切り替え（途中のコマを省く）、カット、カメラ、音で見せる。
  • 走る・もみ合うなどの大きな動作は画面の外に出す（ゾンビを見せない「カット演出」と同じ）。
  • 止まって見える人物は不可：呼吸、体重の移し替え、視線の揺れを全員に入れる。リズムと反応の遅れは人ごとに変える。

カメラ（プレイヤーの視点）

  • 足を運んで歩いている感覚。レールの上を滑る動きは不可。
  • 視点の動きは18コマが標準。
  • 物語上の理由がない見づらさは作らない（明るい場面でも）。
  • 横画面のみ。縦画面のUIは作らない。

時代

  • 2020年ごろ。作中で年は明示しない。
  • テープ式のビデオカメラとデッキは、サークルが「ファウンドフッテージっぽく」撮るためにあえて使う古い機材。

小道具と家

  • 網点の下で見えるのは輪郭、明暗の塊、大きな特徴。そこに手間をかける。
  • 物語の小道具（定点カメラ、三脚、テープ、デッキ、ラジオ、発電機、スマホ）は動く部品まで作り込み、手書きのラベルやガムテープなどサークルの痕跡を足す。
  • 生活感の物は、実物をスマホで3Dスキャンして作る。足りない物は Tripo。
  • 家は「コピペ」に見せない。丸太を一本ずつ変え、汚れ・傷・日焼け・貼り紙・テープの跡を足す。「誰かが住んでいた家」に見えること。
  • 家の中の人は靴下、外にいる人は靴。

未決（ビジュアル）

  • 次に決める外観：ログハウスか、白い下見板張りの洋館風か。同じ間取りで両案を組み、外観と、廊下から玄関を見た画（刷りあり）を並べて決める。
  • 段階0の残り桐生のあごの境目（下から見上げると線が見える）、真琴の襟の後ろの布のギザギザ。
  • 段階2時間帯ごとの光（夕方、20時の停電、23時、2時、3時半、夜明け）。第4章のFPSのHUDと、第11章のテープ再生。
