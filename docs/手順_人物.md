# 手順：人物（Tripo → ゲーム）

ここに書くのは「うまくいった方法だけ」。古いやり方（顔の板を貼る、手製の握り）は載せない。
はまりどころの経緯は NOTES.md。

## 1. 素材
- ChatGPT で全身4方向（正面・左・右・後ろ、Aポーズ、腕と胴にすき間）と頭4方向の計8枚。
- Tripo Pro（H3.1 多視点）。欄：前＝正面、左＝顔が画面の左を向く横顔、右＝顔が画面の右を向く横顔、裏面＝後ろ姿。
- 書き出し：GLB・4K・骨なし。`tripo/<人物>_body.glb`、`<人物>_head.glb`。
- 家の中の人物は靴下の全身（体だけ作り直し。頭は共用）。

## 2. 寸法を測って設定する
- `ortho2.py` で正射投影 → `chars_cfg.json` に A_CHIN, A_CUT, B_CHIN, B_EYE_Z, B_EYE_X, B_EYED, cheek, hb, hp, K。
- `python3 make_prep.py` で `prep_<人物>.py` を生成（雛形は `prep_natsuki.py`。直すのは雛形だけ）。

## 3. prep（`python3 prep_<人物>.py`、1本ずつ。同時に走らせるとメモリ不足で落ちる）
やっていること（順番どおり）：
1. 頭を読み込んだ直後に頂点を溶接する（glTF は UV の島ごとに頂点が分かれている。溶接しないと顔を均したとき裂ける）
2. 頭を目の間隔で拡縮、あごの位置で体に載せる
3. 体は襟の縁（A_CUT）で切る。襟の内側（縁の 1.18 倍より内側）は削って、襟の丸い縁を残す。首の切れ端の小さな島だけ消す（**首より下の島は消さない**。袖などの殻が消える）
4. 頭の首を襟の口に合わせて細め（縁の 0.93 倍）、上に向けてなじませる（あごの3cm下まで、襟から最大4.5cm）。頭の首は襟の 2.2cm 内側まで
5. 顔の範囲を決める：楕円・奥行き・肌色。耳の前の髪の殻は消す。あごの下（下向きの面）も含める
6. 目と口の凹凸を均す（顔の頂点どうしだけで、縁は固定）
7. 頭の正面だけ新しい UV（頭の中心からの方位・仰角）に展開し、Tripo の色と法線を 2048 で焼く
8. 描いた顔を `inpaint_hair` で掃除（髪の筋・輪郭線・背景を肌色に。ほくろは残す）→ 肌の色に合わせる
9. 顔の質感 = 焼いた頭の色 ＋ 描いた顔（1mm のぼかし）。open / closed / talk の3枚を `<人物>_headtex_*.png` に
10. 頭は材質が2つ（髪＝Tripo の質感、顔＝焼いた質感）。Godot は `_face` で終わる材質を差し替えてまばたき・口

## 4. 骨（`chars.make_tripo`）
- MakeHuman game_engine の骨を全員共用。体の重みは MakeHuman の体から移す。
- 首は高さだけで決める：襟の上 3cm から上は首、頭の骨の 7cm 下から上は頭。**頭のメッシュと体の襟に同じ規則**を使う（両方が一緒に回る）。

## 5. 確認
- `view4.py -- <人物> <頭の高さ>` で正面・見上げ・真横・後ろの4方向。
- 合格：どの角度でも顔と頭の境目、首と襟の境目に段差・裂け目・色の違いがない。
