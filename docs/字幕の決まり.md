# 字幕の決まり（2026-11-23、試作277 から）

ユーザーの指示（2026-11-23 7時「表示する台詞行数は最大3行にしよう。あと、話者と字幕の表示、レギュレーション整える」）を、ゲームの表示の決まりにした物。仕組みは godot/scripts/story.gd（本編）と interview.gd（証言の部屋）。直すときはこの紙と両方を直す。

## 画面の下（会話の字幕：lines_box）
- 出ているのは、折り返しを含めて **最大3行**。新しい行が入ると、いちばん古い行から消える（story.gd `_fit_lines`、`MAX_SUB_LINES := 3`）。
- 選択肢と、その答えの行は、一緒に残す（選んだ物と返事が離れない）。
- 古い行は薄くする（濃さ 0.45）。いま話している行だけが濃い。
- **話者の名前**は行の左に出す。出すのは「話す人が前の行と変わったとき」と「字幕が空のとき」。同じ人が続けて話すときは名前を省く。
- 澪の地の文（澪＊）は名前を出さない。

## 画面の左上（澪の証言：tes_box）
- 証言の行は、読める長さで消える。表示は「文字数 ÷ 7 ＋ 2 秒」を 4〜9 秒に収めた長さ。そのあと 1.2 秒で薄れて消える。
- 次の場面の見出しになる行（◇の目当て）は、左上の目当ての欄に出す。証言とは別。

## 証言の部屋（interview.gd）
- 画面の下は本編と同じく最大3行。話者の名前は、話す人が変わったときか、字幕が空のときだけ。

## そのほか
- 章カードが出ている間は、音を全部止める（main.gd `CardHush`）。
- 首を振る・うなずく（＞shake・＞nod）は、動き終えてから次の行を出す（約 0.95 秒）。
