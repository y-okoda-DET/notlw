# 当てる音（2026-11-20）

ユーザー「当てなければいけない音をリストアップして」への一覧。資料だけのスレッドが作った（ゲームのコードには触っていない）。
同じ物を /mnt/project-files/素材の不足/当てる音_2026-11-20.md に置いた。

土台：docs/資料/足りない音とモデル_2026-11-17.md と /mnt/project-files/素材の不足/音の取捨選択_2026-11-17.md。
そこから後に入った場面（行きの車、第2〜8章の筋の直し、第7章の沢、第11章の早送りなど）を、入口の作業ブランチ claude/project-thread-rf40ea（1518847）の
godot/story/*.txt と godot/scripts/*.gd で、**どの音の名前を鳴らしているか**を読んで突き合わせた。
遊んで耳で確かめたのではない（Claude は聞けない）。「鳴っていない」はコードで見た限り。

## 読み方
- **いま**：× 鳴らない（音が無い、または鳴らす口だけある）／仮 数式で作った音／代用 別の場面の音を借りている
- **当てる素材**：共有フォルダにあって、まだゲームに入っていない物（場所を書いていない物は /mnt/project-files/ の直下。同じ物が 音/素材_2026-11-17/ にもある）。「要る」は届いた中に無い物（下の「要る素材」にまとめた）
- 音を入れる作業（切り出し、ゲームにつなぐ）は入口のスレッド。
