# 試作292 を、遊ぶのに近い形でもう一度レビュー

2026-11-26。方法は前回（[レビュー_試作292_SSR.md](レビュー_試作292_SSR.md)）と同じ SSR（Maier ほか 2025）で、36人も質問も同じ。違うのは、遊び終えた側の資料だけ。前回は台本と21場面だったので、第四章の照準と三脚の場面が回答者に届いていなかった（ユーザーの指摘）。今回は、遊ぶのに近い形にした。

## 何を変えたか

- **画は360枚。** 全章をおよそ10秒ごとに撮った。第四章（3時半）は、三脚を取ってから倒れるまで1秒ごと（[遊ぶ形_第四章の画.jpg](遊ぶ形_第四章の画.jpg)）。
- **一回の通しを、起きた順に書き起こした。** 台詞のほかに、音（「（音：鈍い打撃音）」など 355か所）、遊ぶ人の操作（「（操作：三脚を振り下ろす。頭に当たる）」など 100か所）、画面で起きたこと（照準が出る・消える）を入れた。［画 NNN］が出た所で、その瞬間の画を見る。
- **ストアの段（段階A）は、前回と同じ物。**
- **足りない所：** 証言三と最後の再生の章だけ、画が少ない（証言三は7枚、再生は5枚）。この2つはテレビの中の画も一緒に描くので、ほかの章の10倍ほど時間がかかったため。再生の章の後半は、字幕と音だけで読んでいる。

## 先に結論

- **「3時半に何が起きたかつかめない」は、21人から1人に減った。** 前回の訂正どおり、これは確かめ方の穴だった。今回は「最後のテープで、三時半の血だらけの人が夏希だったとわかった」と、裏返しが届いた人が多い（P20・P22・P24・J05 など）。
- **代わりにいちばん多い指摘は、第四章の照準と「頭を狙え」（17人）。** このうち14人は「ここだけ普通のゲームに戻って浮く・冷める」、3人は逆に「戦うのが一回で、すぐ終わる」。決定事項（2026-11 の第4章）にあるとおり、ここだけ別のゲームの画面になるのが狙いなので、狙いは届いている。「狙いはわかる」と書いた人も多い（J02・J05・J06・P06・P11）。ただ、選考・批評の6人のうち5人がこれを挙げ、J01・J03・J06 は「UI は作品世界の中、という約束をいちばん大事な場面で破っている」と、同じ言い方をしている。展示で見られると、ここに意見が集まる。
- **操作が見えて、良かった所に手の作業が入った。** 発電機の「チョーク　引いてから」は7人、真琴の「ゾンビなんて、いない」から貼ったテープを炎ではがす流れは17人。その一方で「板打ち・目張り・板外しが長い、ゲージが無いので合っているかわからない」も13人いた。
- **字幕が重なって読めない（14人、前回8人）。** 前の行が薄く残って三行重なる画が、360枚の中にたくさん入っている。網点の上だと読みにくい、と書いた人が多い。
- **点数と値段は、前回と同じ幅の中にある。** 「9.99ドル払ってよかった」は遊び手30人中22人（前回22人）。払ってよかった額の中央値は12ドル（前回11ドル）。選考・批評の6人は、全員15ドル以上。遊んだ後の自分向けは 3.45（前回3.34）。どれも、同じ資料でも動く幅の中。

## 私の見立て（一つだけ）

**次に一つ直すなら、字幕の重なり。** 前の行が薄く残って三行重なる画で、肝心の台詞が網点に沈む。14人がこれを挙げ、選考・批評の6人のうち4人が入っている。照準は狙いどおりに効いているので、触らなくていいと思う。作業の長さとゲージが無いことも、決めた方針どおりの反応と読む。字幕は、残す行を一つにするか、薄く残す行を網点の上でも読める濃さにするか。どちらにするかは、本物の画で並べて決めるのがよい。

## 限界

- 人の回答と比べていない。36人とも同じモデルが演じた。
- 音は聞けず、操作もしていない。音と操作は、文字で書いて渡しただけ。
- 画は CPU で描いた 960×540。網点と字幕の見え方は、本物の GPU と違うかもしれない。
- 自動の通しは、毎回同じ選択肢を選ぶ。
- 証言三と再生の章は、画が少ない。
