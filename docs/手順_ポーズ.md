# 手順：ポーズ（腕・手・持ち物）

## 仮定してはいけないこと（全部、一度はまった）
- 「骨の −Z が手のひら」：この骨格では **+Z が手のひら**。必ず `chars.palm_sign` / `palm_dir`（親指が生える側で測る）を使う。
- 「指の骨の X 軸で回せば曲がる」：骨ごとに向きがばらばら。指は `chars.curl_finger`（世界座標で「指の向き × 手のひらの向き」の軸）で曲げる。
- 「行列を組めば向きが決まる」：左手系の行列は負のスケールに分解されて面が裏返る。物の向きは右手系（X = Y × Z）で組む。
- 「親子付けした後も位置を毎コマ書いてよい」：スケールが 0 に潰れる。親のある物は置き直さない。
- 「Blender で合っていればゲームでも合う」：名前が `cam` で始まる物は書き出しの掃除で消える、など。書き出した版で確かめる。

## 腕
- `arm_to(rig, side, 手首の位置, 肘の向き)`。肘は胸の中心線を越えない（自動で止まる）。
- 手のひらの向きは `palm_to`。ねじりは前腕 75° + 手首 25° まで（越えると「別の腕の手」に見える）。
- 頭を大きく回すときは首と頭に分ける（大河：首 26° + 頭 36°）。

## 持ち物（作業中）
- 物を先に決め、手を物に合わせる。
- **手の形の正解は写真から取る**。言葉の条件（指は背面、親指は縁）を並べて組むと、一つ直すと別の一つが崩れる。持ち方ごとにユーザーに参考写真（正面・横・本人の目の3枚）を頼む。

## 判定（数値で落としてから、人間の見方で見る）
- 手の確認画は必ず「手のひら側」「甲側」「本人の目」から。
- 手のひら側から爪が見えたら、手のひらと甲が逆。
