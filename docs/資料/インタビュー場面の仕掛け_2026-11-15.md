# インタビュー場面の仕掛け（2026-11-15、ユーザーと決めた。スレッド「インタビュー場面の遊ばせ方を考える」）

企画書「後半の組み直し」のインタビュー3回（証言 一・二・三）に、FPS の場面と同じ種類の「急に遊び方の型が変わる仕掛け」を入れる。ここに決めたのは方向と流れ。画（ビジュアル）はまだ詰めていない（下の「まだ決めていないこと」）。

## 考え方（ユーザーの気づき、2026-11-14）
- 第4章の FPS が効くのは、別の作品・ジャンルの型を借りているから。しかも借りた型が、澪が自分を当てはめている物語の型（ゾンビ映画のヒロイン）になっている。型そのものが澪の自己欺瞞を語る。
- インタビューでも型を借りる。借りるのは2つ：
  1. **会話の決闘**（タランティーノ。『イングロリアス・バスターズ』冒頭の農家の場面と、地下の酒場の「指3本」の場面）：世間話の下で緊張が上がり、本当のことを言いすぎた一語で正体がばれる。聞き手は最初から知っている。
  2. **ノベルゲーム（恋愛アドベンチャー）の型**：「正しい答えを選べば受け入れられる」という澪の考えそのもの。立ち絵、文章の窓、選択肢、セーブとロード。特定のノベルゲームには寄せず、型だけ借りる。
- ノベルゲームの型は3回とも出すと色が強すぎる（ユーザー）。驚きは3回目に一度だけにする。

## 流れ
**証言 一（桐生）：会話の決闘だけ**
- 明るい部屋（作中で初めての昼の光）。聞き手はまず本題に入らず、映画の話、お茶の話、「桐生さんはどんな監督でしたか」をする。
- 聞き手の手元に、家族から預かった桐生のテープ。話の間、指で回したり置き直したりして、ずっと画に入っている。
- プレイヤーは前半の証言の文を拾って答えを組む（いまの決め事のまま）。嘘は通る。

**証言 二（陽太）：決定の音が一度だけ**
- 一と同じ決闘。うまい答えを決めた瞬間に、ノベルゲームの「決定」の小さな音が一度だけ鳴る。画面は変えない（立ち絵が一瞬出る案は、ユーザー「やりすぎ」で取った）。

**証言 三（夏希）：一語で滑り、部屋が平たくなる**
- 危ないのは嘘ではなく、本当のことを言いすぎること。証言の文はどれも本当なので、プレイヤーは安心して拾う。その中に、3時半に廊下にいた人しか知らない一語（例：「勝手口」）が混ざると、聞き手の手が止まる（指3本と同じ仕掛け）。これは決まっていた「3回目だけ、現場と合わない文を選ぶと聞き返される」の形を鋭くしたもの。
- その瞬間に部屋が平たくなる：聞き手は立ち絵に、画面の下に文章の窓、隅に「ロード」。
- ロードすると滑る前に戻れる。ただし聞き手だけが覚えている（「さっきも、そうおっしゃいましたね」）。
- ロードのたびに、書き起こしには消した答えが二重線で積もり（いまの「選ばなかった言葉は二重線」と同じ仕組み）、セーブの一覧は同じ時刻の記録で埋まっていく。
- 何度やり直しても、最後に聞き手はテープを机に置く。「勝手口のことは、テープには映っていません」。追及せず、録音を止めて礼を言って帰る。ばれたのかどうかはわからない。
- 最後のセーブの枠に「上書きしますか？」とだけ出て、第11章へ。テープの録画ボタンの上で止まる指につながる。

## この形にした理由
- 驚きは3回目に一度だけ。FPS と同じく「その時だけ型が変わる」。2回目の音が伏線になる。
- 型が変わる理由が作品の中にある：言ってしまった言葉を取り消したい気持ちがロードを呼ぶ。それでも取り消せないことが、この作品の問い（言わなかった一言、言ってしまった一言）になる。
- 怖さの種類が前半と変わる：暗がりの何かではなく、明るい部屋の礼儀正しい人が怖い。
- 新しく作る物が少なく、画の質を保てる：明るい部屋、机・お茶・テープ・聞き手の手、聞き手の立ち絵（表情違い数枚、ChatGPT の画像生成）、文章の窓とセーブの一覧。

## まだ決めていないこと（次の作業）
- **画を詰める**（ユーザー 2026-11-15「このビジュアル詰める作業が必要だね」）：インタビューの部屋（昼の光と刷り）、聞き手の見せ方（1・2回目の3Dでどこまで映すか）、平たくなった画面（立ち絵、文章の窓、選択肢、セーブの一覧）を、刷りの紙と書き起こしの見た目でどう作るか。取り決めの「生成AIらしい UI は不可」に当てて、角丸の箱やグラデーションにしない。
- 聞き手が何者か（記者、ドキュメンタリーの作り手など）と、映画の話の中身（docs/台詞の方針.md の「映画の題名を抑える」に合わせる）。
- 証言 三で滑る一語の候補（「勝手口」のほかに）と、その一語を拾える前半の証言の文をどこに置くか。
- 澪の顔は見せない（細かい表情を見せるのは難しい、ユーザー 2026-11-14）。

## 取った案（同じ議論で出して、取らなかった物）
- 再現VTR（安い再現ドラマの中で演じる）：質の高い画にするのが難しい（ユーザー）。
- 証言で夜を巻き戻す、手の小さな遊び（ラベルをはがす、机を叩く、紙コップ）、澪の顔を作る：選ばれなかった。顔は細かく見せるのが難しい（ユーザー）。
- 『羅生門』『シン・ブルーライン』、嘘発見器、ワイドショー、『パリ、テキサス』の型：候補として出したが、タランティーノの会話の決闘とノベルゲームの組み合わせを選んだ。
