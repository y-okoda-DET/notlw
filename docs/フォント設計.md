## 考え方：文字を3つに分ける
| 何の文字か | 書体 | 理由 |
|---|---|---|
| 紙に刷られた文字（緑のカードの上：章扉、二十三時、扉の終わりのやりとり） | しっぽり明朝 B1 | 築地の五号明朝がもと。インクのにじみが形に入っていて、2色のリソグラフ刷りの画と同じ「刷った物」に見える |
| 人の言葉・画の上に出る文字（台詞、澪の答え、操作の説明、［扉］などの表示、選ぶ言葉） | BIZ UD明朝 Bold | 横線が太く、小さくても読める。字幅がそろう UD（UDP ではない）。一字ずつ打っても行が揺れず、句読点のあとに間が残る |
| 機械が出す文字（ビデオカメラの REC・STBY・時刻・WIDE、開いた液晶の時刻） | ドットゴシック16 | カメラ自身の表示という作品内の理由がある。ドットの字はここだけ |

- カードの上に BIZ UD明朝を置かない。画の上にしっぽり明朝を置かない（骨格が違い、並ぶとちぐはぐに見える）。
- 物に刷られた文字（ラジオの目盛り、カレンダー、看板、カメラの本体）と手書き（絵コンテ、帳面）は今までどおり（Noto Sans CJK、Yomogi。画像に描き込むだけ）。

## 章カード（main.gd make_card）
- 題（150）：しっぽり明朝 B1 **Medium**、**鉤括弧なし**、**長体85%**（横だけ 0.85 倍）、字間 0.16em。「ルール」「籠城」。
- 小さい字（「第 一 章」46、問いの文 36）：しっぽり明朝 B1 **SemiBold**、長体なし。問いの文は字間 0.02em。Medium や Regular だと小さい字がかすれる。
- 長体は 75% まで詰めるとカタカナが別の字に見える。85% まで。
- 色・地・青版のずれ・紙の粒は今のまま（CARD_BG、CARD_INK、CARD_GHOST、CARD_GRAIN）。
- 扉の終わりのやりとり（door._show_end）の問いの鉤括弧は、発言の引用なので残す。書体は同じ決まり（しっぽり明朝 B1 SemiBold）。

## 台詞と画の上の文字（story.gd _label、SAY_SIZE）
- BIZ UD明朝 **Bold**、**32px**（1080p で。ユーザー決定。46px・42px は「画面の静けさと合わない」ので不可）。名前は台詞の 0.73 倍。
- **袋文字（縁取り）はやめる**。今の青の縁取り（outline 5）と青のずらし影は外す。
- **シャドウは「弱」**（ユーザー決定）：色は黒に近い青 (6, 22, 40)＝刷りの2版が重なったいちばん濃い色。字を約3px 太らせた形を、ぼかし 12px（ガウス）、濃さ 45%（見本 spec5.py の alpha 1.1）、ずらし (1, 2)。狙いは「シャドウがかかっていると一瞬気付かないが読める」。濃くすると広告のように見える。
- 操作の説明（上端）は同じ書体の 20px、同じシャドウ。
- Godot の Label の影はぼかせない。実装するときは、ぼかした影を別に作る（例：字と同じ Label を SubViewport かシェーダーでぼかして下に敷く）。見本と同じ見え方になったかを、pck から撮った画で白い所（居間のスクリーン）と暗い所の両方で確かめる。
- 字の大きさを選ぶ設定は、設定の画面を作るときに考える（サイレントヒルf は3段階）。

## カメラの表示（story.gd FinderFrame、main.gd の Label3D）
- ドットゴシック16。REC・STBY・時刻は 32、WIDE は 26（16 の倍数に近い大きさで。にじませない）。
- 開いた液晶の時刻（main.gd の Label3D）はいまフォントの指定がなく、Godot の組み込みのサンセリフで出ている（取り決め4に反する）。ここもドットゴシック16にする。
