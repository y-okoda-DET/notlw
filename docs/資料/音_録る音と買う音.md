# 録る音、買う音、買う場所（2026-11-11）

クリエイターさんの素材リストを、「自分で録らないと困る物だけ録る」に絞り直したもの。

## 1. 録る（2つだけ）

| 音 | 録り方 | 理由 |
|---|---|---|
| ノック（手のひら） | 同じ扉を、手のひらで不ぞろいに、だんだん力を抜いて叩く。テイクは10本以上。一年前の陽太の「いたずらの元気なノック」も別に数本 | 基準そのものの音。弱くなっていく並びは売っている素材ではそろわない |
| ラジオの選局 | 実物のAMラジオで、局のない所の雑音、ダイヤルを回す音、局が近づいて離れる所を録る。夜の方が遠くの局と雑音が多く入る | ダイヤルの動きと合っていないと嘘に聞こえる。放送の中身（ニュースや曲）は別に用意して、ゲームの側で混ぜる |

道具は、まずスマホの録音で十分。扉の近く（30〜50cm）で、部屋の響きが少ない時間に。

**必要になったら録る**：板打ち（素材を入れて弱かったら）、ビデオデッキ（実機が手に入ったら）。

## 2. 買う（まず無料の所から）

条件は全部に共通：残響が焼き付いていない乾いた音、音楽や声が混ざっていない、ライセンスが商用可。

| 音 | 探す条件 |
|---|---|
| 雨と嵐 | 屋内から聞いた雨（屋根、窓）。強さ違いを2〜3本。2分以上あって、つなぎ目が目立たずに繰り返せる物 |
| 風 | 建物に当たる風。雨と別の素材にして、強さを変えられるように |
| 雷 | 遠い物と近い物。ラジオの雑音を作るのにも使う |
| 発電機 | 小型の持ち運べる発電機。引き綱を引く音、始動、回り続ける音（2分以上）、かぶって止まる音。1本の録音でそろっている物が一番よい |
| 停電 | 冷蔵庫の唸りが止まる音、ブレーカー |
| 発電機のつまみ・スイッチ類 | 小さな機械のつまみ、レバー、スイッチ |
| 1章の生活音 | 料理（切る、煮る）、食器、撮影機材（三脚を広げる、ビデオカメラのボタン） |
| 板打ち | 金づちで釘を打つ、板を当てる、板を持ち上げる |
| 足音 | 家の中は靴下で木の床（1歩ずつ8本以上）。外は靴で濡れた地面と砂利 |
| 扉と階段 | 木の扉の開け閉め、蝶番、階段のきしみ |
| 紙 | 冊子をめくる音（メニュー用） |
| ビデオデッキ | テープを入れる・出す、走行音、早送り・巻き戻し |

**作る**：照準の命中音（乾いた短い合成音）。私が作れる。

**人に頼む**：声（扉越しの夏希、地下のうめき声、ラジオの臨時ニュース・トーク・外国語、テープの中の声）と、ラジオの音楽の局の曲2〜3本。声を入れる範囲が決まってから。

## 3. 買う場所（上から順に探す）

| 場所 | 値段 | 使える条件 | 向いている音 |
|---|---|---|---|
| 効果音ラボ（国内） | 無料 | 商用可、クレジット不要 | 日本の家の生活音、扉、足音、紙 |
| Sonniss の GDC Game Audio Bundle（毎年3月ごろ出る無料パック） | 無料 | 商用可、クレジット不要 | 雨、雷、風、機械、発電機 |
| Freesound | 無料 | **CC0 の物だけ使う**（CC-BY はクレジットが要る、NC は商用不可なので使わない） | 何でも。発電機、ラジオの雑音、ビデオデッキ |
| Splice（友達のすすめ） | 月額（いちばん安いプランで月100本、12.99ドル。解約しても落とした物は使える） | ゲームに使える、クレジット不要（音だけを素材として再配布するのは不可） | ラジオの音楽の局の曲を、ループを組み合わせて作るとき。短い効果音（紙、缶、スイッチ）。長い環境音（屋内の雨、発電機）は少ない |
| A Sound Effect | 有料（1本数千円〜） | 買い切り、商用可 | 上で見つからなかった物（雨の屋内録音、発電機、VHS） |

- 規約は変わることがあるので、落とした日の規約を控えて、使う前に docs/素材とアドオン.md に書く（決まり）。
- 無料で足りなかった物だけ買う。買う前に候補を見せる。

## 4. 聴き比べ方

- 候補は1つの音につき3つまで。残響・長さ・ライセンス・混ざり物は、私が波形と中身のデータで先に外す。
- 3つは、ゲームに組み込まずに聴き比べのページで聴く（2026-11-11 ユーザー OK）。音量をそろえ、雨のように長く鳴る音は繰り返しのつなぎ目まで聴けるようにする。
- 残った1つを仮の音としてゲームに入れる。雨と発電機の重なり、階ごとの聞こえ方は、そこで歩いて確かめる。

## 5. 受け取った収録（2026-11-12、/mnt/project-files/音/収録_2026-11-12/）

- ノック_1回目.wav（45秒、48kHz/24bit、ほぼモノラル）：手のひらで13回、1回に2〜3打。打つ間は0.2〜0.36秒で不ぞろい、回の間は約3秒。ピークは最初 -2 dB から最後 -14 dB まで、だんだん弱くなる。音の中心は 600Hz 以下（拳の硬い音ではない）。打った後30 dB 落ちるまで約10ミリ秒で、部屋の響きはほぼ入っていない。録音の地の雑音は約 -48 dB で、その半分は150Hz 以下の低い唸り。最初（3秒ごろ）と最後（42秒以降）に打つ音でない物音、9.5秒ごろに低い音がある。切り分けで外す。
- ラジオ_1回目.wav（69秒、ステレオ、スピーカーを部屋で録った音）：大半は雑音で、局が入る所（12、14〜16、32、39〜40、45、65〜68秒ごろ）と、局の間のピーという混信の音（約2.9kHz、3.3kHz）がある。**実在の放送の声や曲が聞き取れる所は、権利があるのでゲームに使わない**。使うのは雑音、混信の音、局が近づいて離れる移り変わりだけで、放送の中身（臨時ニュースなど）は別に作って重ねる。
- Claude は耳で聞けないので、上は波形と周波数で調べた結果。
- ノック_内側_1回目.wav（52秒、扉の内側、マイクを扉から5〜10cm）：26回のうち16回が音割れ（波形の頭が平らに切れている。3〜35秒の強いノック）。割れていないのは 22〜26秒と 36〜50秒の弱いノック。弱い所はそのまま使える。強い所はマイクを20〜30cm離して録り直す（Claude の「5〜10cm、強めに」の指示で割れた）。地の雑音は約 -49 dB で、90Hz の唸りが半分以上。
- 外側の録音（ノック_1回目.wav）は第7章（陽太が外から叩く）に使う。
- ノック_内側_2回目.wav（30秒、扉から20〜30cm）：まだ全部の回で音割れ。ただし1か所あたり約1ミリ秒（50サンプル前後）の浅い割れ。地の雑音は約 -57 dB に下がった（1回目より8 dB静か）。最初の0.8〜7秒は叩く音以外の物音が混じる。ffmpeg の adeclip で割れを埋めた版（-6 dB 下げてから）を「_割れを直した版.wav」として置いた。波形の頭の平らな所は丸く戻った（_赤が元_青が直した版.png）。耳での判断はユーザー。直した版が不自然なら、録音アプリの入力を下げるか、扉から1mで録り直す。

## 7. 雨と発電機の聴き比べ（2026-11-12）

- ページ：https://claude.ai/artifact/CuidawYpKoLpqbLmf3Rrgx （ユーザーだけが開ける）。候補は雨 rain_05・07・08、発電機 本命・freesound・使えるかも４。全部 -24 LUFS、繰り返しのつなぎ目は3秒重ね。雨にはノック（内側2回目の直した版、内側1回目の弱い終わり）を重ねられる。発電機は階の聞こえ方（1階 -14dB・400Hz、2階 -30dB・180Hz、仮）を試せる。
- ユーザーの評価はページの db の ratings コレクション（候補ごとに1つ）。ArtifactData の list で読める。作った音の作り方：scratchpad の mkloop.py（ffmpeg で切り出し、numpy で重ねてつなぎ、ebur128 で音量をそろえる）。
- 2026-11-12 風（4本）、雷（4本）、家の中の足音（4本）、停電（ブレーカー・冷蔵庫）を足した。つまみ・スイッチ・紙・VHS の短い操作音は、候補が1つずつなのでゲームに入れて決める。

## 8. 雨の探し直し（2026-11-12）

- 聞こえ方は「窓越し」（ゲームの側で 2.5kHz より上を落とし、高い音を -6dB。仮の値）。素材は屋外の雨でもよいが、薄いノイズが乗っていない物。
- 条件：2分以上、強さが一定、雨粒の一つ一つが聞き分けられる（ザーだけの物は合成や加工のことが多い）、WAV か高い音質の MP3。「睡眠用」「ホワイトノイズ」と書かれた物は避ける。
- 検索の言葉：rain on window、rain on roof、rain interior、rain cabin。Freesound は CC0 に絞る。
- 2026-11-13 探し直した雨4本（Pixabay、/mnt/project-files/音/素材_2026-11-12/）：dragon-studio gentle-rain-07（90秒）・01（10分）、eryliaa gentle-rain（9分、モノラル）、indoor-hard-rain（15分）。6〜14kHz の強さの幅（大きいほど雨粒の間が静か）と、5ミリ秒ごとの音の尖り具合（大きいほど雨粒がはっきり）で比べた。外した VSQ：幅 2.4〜5.5dB・尖り 4〜74。dragon07：10.8dB・98、dragon01：6.9・51、eryliaa：7.1・55、indoor-hard：2.8・10（VSQ と同じ形で、薄いノイズの疑い）。聴き比べのページに【新】として並べ、最初から窓越しで鳴る。
