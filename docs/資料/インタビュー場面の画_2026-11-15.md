## 1. 部屋：澪の実家の客間、障子の昼（陰翳）
- **場所は澪の実家の和室の客間**。聞き手が訪ねてきて、澪が玄関を開けて通した。序章で警察に開けた扉に続いて、澪が自分で開けた二つ目の扉になる。最後に聞き手が「礼を言って帰る」のも、ここなら自然。
- **光は障子一面の昼の光だけ**。部屋の照明はつけない。障子は刷りの中で「紙の白そのもの」になる。作中で初めて、紙の白が光として画面の大半を占める（夜は青緑、夕方は橙だった）。家の夜と夕方の刷りの式はそのまま（全編に同じ処理をかける、企画書）。昼は夕方の刷り（look=0）に、光の量で白を多くするだけ。
- 障子の外に庭木を置き、葉の影を障子に落とす（案の画ではまだ弱くて刷りに出ていない。本番で詰める）。動くのは葉の影だけ。
- 3回目に部屋が「平たくなる」とき、障子の部屋はもともと紙と桟の平面なので、陰影が抜けただけで背景画になる。昼の部屋を障子にした一番の理由はここ。

## 2. 聞き手の見せ方（証言 一・二）：顔は画の外、手とテープだけ
- 澪は座卓をはさんで座っている（目の高さ約 0.8m）。聞き手は障子を背にして座るので、逆光で体は青の網点の影になる。**顔は画面の上の端で切れて、1・2回目は一度も映らない**。プレイヤーが見下ろせるのは机の上：聞き手の両手、桐生のテープ（VHS、手書きのラベル）、帳面、録音機、湯呑み2つ。
- 会話の決闘の主役は手。話の間、右手の指がテープの上で動く（回す、置き直す、ラベルを撫でる）。手元に寄った画（案の画 2）を、答えを組む間の基本の画にする。
- 橙の版は湯呑みのお茶だけに残す（昼の部屋で暖かい物はそれだけ）。
- **3回目に部屋が平たくなった瞬間、初めて聞き手の顔が見える**（立ち絵）。顔を見せないまま来たので、ノベルゲームの型に入ったことが、顔が出ることそのものでわかる。

## 3. 平たくなった画面（証言 三）：ノベルゲームの配置を、同じ紙とインクで
- 借りるのは配置だけ（立ち絵が中央、画面の下に文章の窓、名前の札、待ちの▼、隅の「ロード」）。窓の作りは刷りの紙（角丸、半透明、グラデーションにしない。取り決め4）。
- **背景**：同じ部屋の同じ角度から、光と影を抜いて、物の色だけの平らな網点にする（Godot では光を受けない材質に切り替える。案の画 3）。
- **立ち絵**：画像生成で描く。同じ2色の刷り。紙から切り抜いた形で、白い切り代と、平らな青の網点の影がつく。表情は4枚（微笑み、目を細める、真顔＝手が止まる、目を伏せてテープを置く）。プロンプトは /mnt/project-files/インタビュー/画像生成_1回目.md。
- **文章の窓**：画面の下の幅いっぱいに、書き起こしの紙を一枚重ねる（角は四角、影は平らな青の網点）。名前の札は切った紙片を貼った形。字は今の決まりのまま（BIZ UD明朝 Bold 32px、名前は小さく、札はしっぽり明朝）。ただし紙の上なので、字は白抜きでなく青緑のインクで刷る。消した答えは今の「選ばなかった言葉」と同じ二重線で窓の中に積もる。
- **ロードの一覧**：書き起こしの一覧の形。番号、小さい背景の刷り、時刻（ドットゴシック16：録音機の時刻なので機械の文字）、消した答えの頭。どの記録も同じ秒（例 01:14:08）。最後の枠に「上書きしますか？」。
- **聞き手が何者か（2026-11-15 ユーザー OK）**：本を書くためにこの件を取材しているノンフィクションの書き手（50代の女性）。ゲームの画面の文字は全部「数か月後のインタビューの書き起こし」なので、その書き起こしを作っているのがこの人、ということになる。ノベルゲームの文章の窓が書き起こしの紙なのも、この人の原稿だから。名前の札はいまは「聞き手」。名前を出すかは台本のときに決める。

## 4. カット割りと構図：小津の型（2026-11-15、ユーザー「小津っぽい画角とかもカッコ良さそう。基本のカメラの方針はいい。カット割と構図、カメラワークでより洗練させて、映画っぽく見せたい」）
障子の部屋から出たユーザーの案。Claude の案は下のとおり（返事待ち）。絵コンテは /mnt/project-files/インタビュー/画の案_1回目/5_カット割り_絵コンテ.png。
- **カメラは一度も動かさない。カットだけでつなぐ**。高さは座った人の目より低い所（約 0.5〜0.6m）で、水平。レンズは標準（50mm 前後）。切り替えは全部ふつうのカット（溶けない、揺れない）。
- **二人とも正面から撮って、どちらも口元で画を切る**（聞き手は逆光、澪は障子の光を正面から浴びる）。正面の切り返しで、二人ともこちら（プレイヤー）に向かって話す。1・2回目の「聞き手の顔は画の外」をここに合わせ、澪の顔も見せない（ユーザー 2026-11-14）。
- **型を借りる理由**：小津の正面・中央・左右対称の構図は、そのままノベルゲームの立ち絵の構図になる。証言 三で一語が滑ったとき、カット3（聞き手の正面）からカットを切らずに陰影だけが抜け、口元の上に顔（立ち絵）が出る。日本の家族の映画の礼儀正しい型が、会話の決闘の怖さとノベルゲームへの滑りを両方運ぶ。澪が定点カメラを置いた作品なので、据えたままのカメラにも作品の中の理由がある。
- **カットの並び（証言 一）**：1 空（床の間）→ 2 引き（横から低く、床の間の柱で画を割る。聞き手は柱の陰、澪は光の側）→ 3 聞き手の正面 → 4 澪の正面 → 5 手元（答えを組む間。プレイヤーの操作の画）→ 3 に戻る。証言 二は同じ並びで、決定の音のあとに 1 の空を一度だけはさむ。証言 三は 3 から平たくなる → ロード → 最後は 7 空（聞き手が帰ったあとの部屋と、置いていったテープ）→「上書きしますか？」。
- 空ショットは小津の「枕」。床の間、湯呑み、帰ったあとの座布団。人がいない画で間を作る。
- 引き（カット2）では頭が小さく入る。本番では顔が刷りの影に沈む角度にする（仮の人形では横顔が見えている）。

## 6. 動くカメラ（2026-11-15、ユーザー「ちょっと淡々としてる？タランティーノっぽいカメラワークを混ぜると？何種類か見て判断したい」「タランティーノ以外のパターンも見たい」。Claude の案、返事待ち）
動く画は /mnt/project-files/インタビュー/カメラワーク/（通しの動画、10種の GIF、一覧）。Blender の箱の部屋で描いて刷りに通した物。人は仮の人形。
- タランティーノ：T1 ゆっくり寄る（『バスターズ』の農家の机）、T2 真上、T3 机から見上げる（トランク）、T4 回り込み（『レザボア』の食卓）、T5 極端な寄りのぶつ切り（お茶・指・録音機の秒・澪の拳）。
- ほか：N1 ヒッチコックのめまい（下がりながら寄せる）、N2 ハネケの据えた長回し（高い隅、定点カメラの目）、N3 ウェス・アンダーソンの振り、N4 リンチの闇から寄る（襖の隙間＝E）、N5 デ・パルマの二焦点（手前のテープと奥の澪）。
- Claude のおすすめ：**回を追うごとにカメラが動き出す**。証言 一は据えたまま（小津）で、頭に一度だけ N2。証言 二でタランティーノが入る（長い問いに T1、決定の音の直前に T5、決定の瞬間に T2）。証言 三は T4 で回り続け、一語が滑った瞬間に N1 のめまい→平たくなる。理由：止まったカメラ＝澪が話を握っている、動くカメラ＝握れなくなっていく。めまいは「滑る」をそのまま画にする。T3・N3・N4・N5 は控え。
- 「カメラは一度も動かさない」（4）は、このおすすめが通れば証言 一だけの決まりになる。
- 2026-11-15 ユーザー「全部良くて悩ましい。タランティーノ3はいらない」→ T3 は外す。ユーザーの心配「通しで見ると騒がしい」「対話してる感じは担保されるか」への Claude の答え（返事待ち）：
  - 動きは1回の証言に2〜3回だけ。プレイヤーが答えを組む間（手元の画）は必ず止める。動くのは聞き手が話している所と、決定の音の前後だけ。
  - 対話の背骨は正面の切り返し（3 と 4）のまま。動きはその上に乗せ、動いたあとは必ず相手の正面に返す。
  - 二人を一つの動きか一つの画でつなぐ N3（振り）・N5（二焦点）・T4（回り込み）は対話を運ぶ。一人だけ・物だけの T1・T2・T5・N1・N2・N4 は「間」の画で、切り返しの代わりには使わない。N3 と N5 を控えから証言 二に上げるのを提案。

- **決まった形**：カメラの使い方（2026-11-15 ユーザー OK「そのおすすめを少し直した形でいきましょう」）：
  - 証言 一：据えたまま（小津の切り返し）。頭に一度だけハネケの高い隅（N2）。
  - 証言 二：タランティーノが入る。長い問いで T1 ゆっくり寄る。やり取りは N3 振り と N5 二焦点 が運ぶ。決定の音の直前に T5 極端な寄り、その瞬間に T2 真上。
  - 証言 三：T4 回り込みが止まらなくなり、一語が滑った瞬間に N1 めまい→平たくなる。
  - 控え：N4 闇から寄る（E の襖の隙間）。使わない：T3。
  - 決まり：答えを組む手元の画では必ず止める。動いたあとは必ず相手の正面に返す。一人や物だけの「間」の画は1回の証言に二つまで。「カメラは一度も動かさない」は証言 一だけの決まりになる。

## 7. 昼の刷りと葉の影（2026-11-15、ユーザー「オッケー進めて」）
