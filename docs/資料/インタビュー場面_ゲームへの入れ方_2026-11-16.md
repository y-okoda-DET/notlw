## 1. 書き出し

`python3 blender/interview/export_interview.py`（Blender の Python）で godot/assets/interview/ に出る。build.sh にはまだ入れていない。

| ファイル | 中身 |
|---|---|

| tree.glb | 障子の外の葉。画に映さず影だけ落とす（cast shadow のみ） |
| kikite_seiza / pinch / stroke / write.glb | 聞き手の形4つ（テープに手／つまむ／ラベルをなでる／書きかけて止まる）。形を焼き込んだ動かない体（骨なし） |
| mio_seiza.glb | 澪。南の座布団に正座、膝の上に拳 |
| portrait_1〜4_*.png | 立ち絵（切り抜き）。1 微笑み、2 真顔、3 目を伏せてテープ、4 目を伏せて小さいテープ |

| scene.json | 座卓・座布団・小物の位置、映さない組（groups） |

人物の元は tripo/interview/（Tripo の体と頭に MakeHuman の手を足して骨で正座させ、形を焼いた物）。作り直すときの手順は
blender/interview/people/README.md。帳面を開いた形（書く手のとき）は render_cams.py の NOTEBOOK_OPEN と同じ置き方
（帳面を (0.13, 0.44)、-4° に引いて見開き2枚、page_L/R.png）で、まだ room.glb には入れていない（書く手のカットを入れるときに足す）。

重さの目安：聞き手 約 15 万頂点、澪 約 21 万、録音機 約 36 万（Tripo を 15% に減らした物）。ユーザーの PC（Intel Arc 130V）で
重ければ、録音機を先に減らす（寄りは C と T5 だけ）。テクスチャはどれも 2048 以下。

書き出した物だけで部屋を組み直して Blender で描くと、形と画像はそろって出るが、全体が暗い（障子の紙を透ける光と、日の当たりが
GLB に乗らないため）。光は Godot で組み直して、証言の動画の明るさに合わせる（障子は裏から光る紙として、放射か半透明で）。

## 2. カメラ（cuts.json）

- 座標は Blender（z が上）。Godot へは (x, y, z) → (x, z, -y)。向きは loc から at を見る（上は +z）、roll は度。
- 1コマ＝1/12秒。刷りの print_fps=12 とそろえて、カメラも 12 コマで動かす（コマの間を補わない）。hold はそのコマを何コマ伸ばすか。
- レンズ：Blender のセンサーは幅 36mm。レンズのずらし（shift_y）があるので、Camera3D は PROJECTION_FRUSTUM、keep_aspect＝KEEP_WIDTH で
  `size = near * 36 / lens`、`frustum_offset = Vector2(0, shift_y * size)` にすると Blender と同じ枠になる（水平を守ったまま枠だけ上下させる）。
- hide：映さない組。people＝聞き手、mio＝澪。聞き手の顔は証言 三で平たくなるまで画に出さない（決定事項）。
- blur：横の流し（N3 振り、T4 回り込み）。px／1920。刷りの前に画面を横にぼかす。
- sway：障子の葉の影の揺れ（証言 一の長回し）。tree の回転 (0.02 sin t, 0.035 sin(t+0.7), 0)、位置 x + 0.03 sin(t+1.3)、t＝2π·sway。
- N5 二焦点（e）は手前のテープと奥の澪の両方にピントが合う画。ゲームではピントのぼけを使わなければそのまま両方合う。
- 並び：ORDER（証言一＝j〜p、証言二＝a〜i、証言三＝q〜u）。答えを組む間（手元のカット o・f）は、プレイヤーが答えを選び終えるまで止める。
  決定の音（証言 二）は h の頭。

## 3. 昼の刷り（look を一つ足す）

インタビューは昼の刷り（ユーザー OK の画は blender/interview/iv/riso.py の `print_frame(day=True, cell=2.6, grain=0.10)`）。
riso2.gdshader は look 0（夕方）と 1（夜）なので、look 2 を足す。違いは青の版の覆い（a）だけ：

```
// 昼の刷り：障子の白だけを紙にして、淡い影（葉の影など）から薄い網点、暗い所だけ濃く
float d = 1.0 - clamp(luma(c_raw), 0.0, 1.0);   // c_raw は scan を通す前の色
a = 0.30 * smoothstep(0.06, 0.28, d) + 0.70 * smoothstep(0.38, 0.92, d);
```

橙の版（b）は coverage() のまま。網点は cell_px = 2.6（夕方 3.6 より細かく、紙の白を多く残す。決定事項 2026-11-15）。

## 4. 証言 三：版ずれ → ディゾルブ → 平たくなる

決定事項 2026-11-16（ユーザー「半ズレからディゾルブでぼやーっと立ち上がってくる」）。作り方の正は blender/interview/seq_post.py の
`dissolve()` と `flat_with()`。

1. t（版ずれ）：N1 めまいの終わりと同じ枠で 1 コマ（3/12 秒から 2 コマ削って溶かしに回す）。riso2 の `slip = (-26, 14)`（px／1080）。
2. 溶かし前半 10 コマ：版ずれの刷りを、ぼかしながら（ガウス 0→14px／1920）平たい部屋の刷りへ重ねて替える（重みは ease）。
3. 溶かし後半 14 コマ：書き起こしの窓を最初のコマから置き、立ち絵（2 真顔）を
   濃さ ease(min(1.4t, 1))、ぼけ 18(1−ease t) px、橙の版のずれ 24(1−ease t) px で立ち上げる（青が先、橙があとから合う）。
4. 平たい部屋：光を消し、物ごとに flat_colors.json の色だけを塗る（unshaded）。人物は映さない。刷りは網なしの平らな3色
   （riso.py の flat=True：紙／青の平網／青緑）。立ち絵は白い切り代（21px 太らせた形）と、平らな青の網点の影 (14, 12)px。
5. 文章の窓：画面の下 800px から下に書き起こしの紙、名前の札「聞き手」、字は青緑、待ちの▼、右下に「ロード」。
   部品は iv/compose.py の window()。最初の一文は「勝手口？」。

ロードの一覧と「上書きしますか？」の画は、/mnt/project-files/インタビュー/画の案_1回目/4_証言三_ロードの一覧.png が案（まだ本物の部屋では作っていない）。
