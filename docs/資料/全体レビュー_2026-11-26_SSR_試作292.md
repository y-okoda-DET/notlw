## 先に結論

- **桐生の映画の題名への不満が、はっきり減った。** 遊んだ後の引っかかりで題名に触れた人は 8人だった。280 は 2回とも 22人と 16人なので、およそ半分になった。台本の中の題名も、13行から 8行に減っている（『REC』『ブレア・ウィッチ』の一つ、ロメロなど）。残った8人は「前半から中盤に多い」と書いていて、後半の重い場面で目くばせに聞こえるという声は消えた。
- **網点で顔が読めないも減った。** 26人と19人だったのが 14人になった。
- **代わりに、3時半（第4章）がいちばんの引っかかりになった。** 21人（280 は 13人と16人）。「うめき声の字幕が並ぶだけ」「誰が入ってきたか、澪が何をしたか、一回ではつかめない」という声。題名の不満が減って、この場面が前に出た形と読む。
- **新しく出た指摘：目張りの場面の真琴が、裸に見える**（8人、選考・批評6人のうち4人）。ろうそくの橙が服の上に広く乗り、肌の色一色に見える。下に並べたとおり、この画は 280 から変わっていない。280 の2回では誰も触れなかったので、今回たまたま目に留まった可能性もある。ただ、選考の役が「展示では誤解される」と書いているので、本物の GPU の画で一度確かめてほしい。[目張りの真琴_280と292.jpg](目張りの真琴_280と292.jpg)（左が 280、右が 292。私の CPU の描画）
- **点数と値段は、280 と同じ幅の中にある。** 遊び終えて「9.99ドル払ってよかった」は遊び手30人中22人（280 は 22人と21人）、払ってよかった額の中央値 11ドル（10.5ドルと9ドル）、選考・批評の6人は全員 15ドル以上。前の2回の差（同じ資料でも1〜2人、1〜2ドル動く）より大きな変化は無い。
- **前回見つけた、自動の通しが第8章の頭で終わる件は直っていた。** 292 は頭から第11章の終わりまで、失敗 0 で通った（845行）。

## やり方（280 との違い）

- 段階A（ストア）：ライブラリの「ストアページ」の文と場面写真 01〜09。280 の聞き直しのときと同じ物（11月24日から変わっていない）。だからストアの段の点の差は、この確かめ方の揺れを表す。
- 段階B（遊び終えた記録）：292 の pck から、280 と同じ章・同じ秒で撮った21場面（[刺激の画_21場面.jpg](刺激の画_21場面.jpg)）と、自動の通しの台本。台本には 280 と同じ5か所の操作の注と、第6章で押した案内を入れた。今回は第8章まで 292 の物で、ログの「(clear 8/8)」も最初から取った。
- 台本の違い（280 → 292）：台詞の頭の「……」が 285行から 114行に減った。桐生の映画の題名は 13行から 8行。車の返答の選択肢の言い方が変わった（「……」が取れた）。

## 私の見立て（一つだけ）

**次に一つ直すなら、3時半（第4章）に、何が起きたかの手がかりを一つ足す。** 題名と網点が減ったいま、21人がそろって挙げる、いちばん大きい引っかかりになった。答えを見せる必要はない。うめき声の字幕だけでなく、たとえば澪の手元か、床の一つの物か、扉の側の音の向きのような、あとで警官の言葉と証言三が裏返したときに「あれか」と戻れる手がかりを一つ。いまは手がかりが無いので、裏返しが「わからなかった」で終わっている人が多い（P04「二回読み返してやっと気づいた」、P09・P25・P30）。

## 限界

- 人の回答と比べていない。36人とも同じモデルが演じ、1組3人で1回ずつ。
- 音は聞けず、操作もしていない。画は CPU で描いた静止画（真琴の服の見え方は、本物の GPU では違うかもしれない）。
- 自動の通しは毎回同じ選択肢を選ぶ。
- 同じ資料でも、人数で1〜2人、金額で1〜2ドルは動く（280 の2回で確かめた）。
