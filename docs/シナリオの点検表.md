# シナリオの点検表（決定が台本に入っているかを機械で確かめる）

使い方：`python3 docs/シナリオの点検.py [台本のフォルダ]`（省略すると godot/story）。全部 ○ なら終了コード 0、× が一つでもあれば 1。
決まり：シナリオの決定を docs/決定事項.md に書いたら、同じ回のうちにこの表へ行を足す。台本を書いた・直した人は、送る前にこれを回す。
台本がまだ無い章は「未」と出る。台本を書いたら、ファイル名を入れて「有る／無い」の行に書き直す。

種類は「無い」（その文字列が台本に残っていてはいけない）、「有る」（入っていなければいけない）、「未」（台本がまだ無い。書くときに守ること）。

## 題名の決まり（表の行のほかに、点検が自動で見る）
- 20時以降の台本（ch2_20、ch2_21、ch2_23、ch4、ch11）で『　』の題名を言ってよいのは桐生だけ。
- 一場面（【　】の一区切り）に題名は一つまで。
- 澪の証言（澪＊）と、扉を見たときの答え（【扉.見る】）には題名を入れない。持ち主の書きつけ（【発電機.テープ】）は題名ではないので除く。
