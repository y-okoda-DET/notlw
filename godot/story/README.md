# 台本ファイル（godot/story/*.txt）

台詞と、その台詞が出るきっかけを、章ごとに1つのファイルに置く。ゲーム（scripts/story.gd、door.gd）はここを読む。
言い回しを直すときは、このファイルだけを直せばよい（書き出しは要る）。順番や条件を変えるときは story.gd も見る。

| ファイル | 中身 |
|---|---|
| ch1.txt | 第1章「定点」 夕方：廊下の撮影、定点のカメラを置く |
| ch2_20.txt | 第2章「籠城」 20時：停電、発電機、ラジオ、窓の板 |
| ch2_23.txt | 第2章 23時：扉の前（時間どおりに進む） |

## 書式
```
// で始まる行は覚え書き（ゲームには出ない）
【名前】            ここから次の【】までが1かたまり。story.gd が名前で呼ぶ
桐生：台詞          人の台詞
澪＊：証言          澪の証言（半年後の声。ページの上に出る）
［操作の案内］       ［ か （ で始まる行は、小さな字の注（話者なし）
？選べる言葉         選択肢。続く字下げした行が、それを選んだときの返事
    夏希：返事
＞名前              ゲームの動き（絵コンテを渡す、明かりが点く、など。story.gd の _do）
12.5 夏希：台詞     行の頭の数字は、場面が始まってからの秒（23時の扉だけ）
桐生→澪：台詞       →澪 →扉 は、言う相手のほうを向く（23時の扉だけ）
```
- 台詞の中の %s は、ゲームが入れる言葉（右・左など）。
- ラジオの文の # は、聞き取れない地名の場所（消さない）。
- 人の名前は 澪・桐生・夏希・真琴・大河・ラジオ。新しい名前を足すときは story.gd の WHO_KEY も。
- 直したら `python3 godot/lang/extract.py`（翻訳の表と、行の折り返しの区切りを作り直す）と、
  `bash godot/check/playthrough.sh <pck>`（通し。出た台詞は $WORK/check/通し_台詞.txt）。
- 名前を消したり変えたりしたら `python3 godot/check/daihon_check.py`（story.gd が呼ぶ名前が全部あるか）。
