# 足りない音とモデル（2026-11-17）

ユーザー「この時点で足りてない音、モデルを整理してまとめて。探したり作ったりする」への一覧。資料だけのスレッドが作った（ゲームのコードには触っていない）。
同じ物を /mnt/project-files/素材の不足/ に置いた。画像生成と Tripo の指示は同じフォルダの「画像生成とTripo_1回目.md」、ユーザーが録る音の録り方は「録る音_1回目.md」。

元にした物：docs/要約.md、docs/企画書.md（実際の時系列、構造と語り、主要シーン設計）、docs/決定事項.md（2026-11-17 まで）、godot/story/ch0〜ch4・ch11（main）と ch5（F のスレッドの作業ブランチ）、docs/資料/第3章の設計・第5章の設計・夏希をゾンビに見せる証拠・音_録る音と買う音、docs/素材とアドオン.md、godot/sound/（仮の音の置き場所と作り方）、tripo/ と godot/props/（いまあるモデル）。

## 読み方

- **優先度**
  - **A**：いま作っている章（序章〜第5章）と、作品の顔（23時の扉、第4章の FPS、第11章のテープ再生）。A.MAZE に出す縦切りに入る物もここ。
  - **B**：次に作る後半（第6章 辻褄合わせ、割り込み「監督」＝桐生の2時、インタビュー）。台本はまだだが、企画書で中身が決まっている物。
  - **C（見込み）**：台本も設計もまだの章（第7章 去年の夏ほか）。企画書から要りそうな物を拾った。章を書くときに増減する。
- **いま**：○ 本番に使えそうな物がある／△ 仮の物がある（数式で作った音、Godot の箱など）／× 何もない
- **作り方の候補**：録る（ユーザーが録る）／素材（Pixabay・効果音ラボ・Freesound の CC0 などから探す。買うのは無料で足りないときだけ）／声（人に頼む）／画像生成→Tripo／Blender（Claude が作る）／Mixamo（ユーザーが落とす）／写真（ユーザーが撮る参考写真）／Claude（数式の音、画面に描く絵）
- 決まり：素材は使う前に docs/素材とアドオン.md にライセンスを書く。Freesound は CC0 だけ。耳での良し悪しはユーザーが決める（Claude は聞けない）。
