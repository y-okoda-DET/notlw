# 手順：ポーズ（腕・手・持ち物）

## 仮定してはいけないこと（全部、一度はまった）
- 「骨の −Z が手のひら」：この骨格では **+Z が手のひら**。必ず `chars.palm_sign` / `palm_dir`（親指が生える側で測る）を使う。
- 「指の骨の X 軸で回せば曲がる」：骨ごとに向きがばらばら。指は `chars.curl_finger`（世界座標で「指の向き × 手のひらの向き」の軸）で曲げる。
- 「行列を組めば向きが決まる」：左手系の行列は負のスケールに分解されて面が裏返る。物の向きは右手系（X = Y × Z）で組む。
- 「親子付けした後も位置を毎コマ書いてよい」：スケールが 0 に潰れる。親のある物は置き直さない。
- 「Blender で合っていればゲームでも合う」：名前が `cam` で始まる物は書き出しの掃除で消える、など。書き出した版で確かめる。

## 骨格を体に合わせる（2026-10-30。手が一発で直らなかった根本の原因）
- MakeHuman の骨の手は Tripo の手より長い（桐生：骨 20.4cm、体 15cm）。そのままだと指の関節が体の指の途中にあり、骨の上では握れていても見た目の指は変なところで曲がる。親指の骨も体の親指と別の場所にあった。
- `make_tripo` で、手の骨を回して拡大縮小し、中指の先を体の指先に合わせる（`hand fit`）。親指の骨も体の親指の先に向けて長さを合わせる（`thumb fit`）。重みはこの後で移すので、体の指が骨についてくる。
- 確かめ方：骨の線を画に重ねて撮る（`pgd.py`）。骨の先と体の指先がずれていたら、ポーズより先にこれを直す。

## 腕
- `arm_to(rig, side, 手首の位置, 肘の向き)`。肘は胸の中心線を越えない（自動で止まる）。
- 手のひらの向きは `palm_to`。ねじりは前腕 75° + 手首 25° まで（越えると「別の腕の手」に見える）。
- 頭を大きく回すときは首と頭に分ける（大河：首 26° + 頭 36°）。

## 持ち物（写真から決めた形。試作14）
- スマホ（`chars.phone_grip3`）：縦長のまま手のひらに。長い辺は指と直角。下の端は小指の上、上の端は人差し指より先へ。指はほぼまっすぐ背面に並び、指先が向こうの長い辺から少しのぞく（曲げは指ごとに、背面と縁に当たるまで）。親指は手前の長い辺に沿って上へ（親指の付け根を回して、指先を縁の外に向ける）。
- 扉を押す（`export_godot.pose_taiga`）：体ごと 16° 前に傾ける（足は扉から 90cm、足首は床に平ら）。手首は目の高さの 9cm 下、肩幅より外（左右 33cm）。手のひらは扉に向け、指は上（少し外へ開く）。腕がほぼ伸びきるように足の位置を決める（届くかは `reach` を数値で出す）。
- 板を持つ（`export_dusk.pose_makoto`）：板はお腹の前、肩の 10cm 下が中心。顔を向けたい相手に面を向けると、自然に 20〜30° 後ろに傾く。手は左右の縁の下の方。手のひらと指は板の裏（下向きの面）に当て、親指は縁を回って表へ。肘は下、脇を閉じる。指は曲げるたびに板を貫通しないか確かめて、当たる手前で止める。

## 持ち物の進め方
- 物を先に決め、手を物に合わせる。
- **手の形の正解は写真から取る**。言葉の条件（指は背面、親指は縁）を並べて組むと、一つ直すと別の一つが崩れる。持ち方ごとにユーザーに参考写真（正面・横・本人の目の3枚）を頼む。

## 判定（数値で落としてから、人間の見方で見る）
- 手の確認画は必ず「手のひら側」「甲側」「本人の目」から。
- 手のひら側から爪が見えたら、手のひらと甲が逆。
