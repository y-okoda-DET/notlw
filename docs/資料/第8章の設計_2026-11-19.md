## この章の役目
- 澪の証言が一行で飛ばした一時間（「桐生さんは、助けを呼びに行きました」「ノックは、しばらく続きました」）を、扉の外の側から、プレイヤーの手で埋める。
- 証言 一で澪は「桐生さんが、そう言ったんです」と答え、聞き手は「約束を、守ったんですね」と返した。その直後にこの章が来る。プレイヤーは「俺でもだ」と言った本人になって、その扉を外から叩く。
- 夏希の告白を消す指を、プレイヤーの指にする（企画書「上書きの残像」）。
- 第7章（陽太、扉は開かない）の前に置かれる、もう一つの「開かない扉」。ただし桐生は去年のノックを知らない。隣に立つ夏希だけが、同じ扉・同じ時刻・同じ言葉だと知っている。これが3時半の「……ようたと、おなじ。また、おなじ」の中身になる。

## ねらう気持ち
- 始めは「頼もしい」。桐生は最後まで面白くて、仕切れる人で、責任を取りに行く。プレイヤーは桐生が好きなまま外へ出る。
- 扉の前で「自分の言葉に締め出される」。怒鳴っても、扉の向こうの澪は正しいことをしている。そうさせたのは自分の一言。
- 山道で「しゃべるのをやめられない人」。撮ることと話すことで怖さを仕切ろうとして、言うべき一つのこと（陽太）だけを言えずに「カット」と言う。
- 終わりは事件でなく「記録だけが残る」。落ちる瞬間は見せ場にしない。画は雨の空のまま回り続け、声と音だけが残る。

## 画の型：全編がファインダー
- 桐生が階段の下でカメラを三脚から外した瞬間から、画面はカメラのファインダーの画になる（それまでの十数秒だけ、桐生の目）。表示はカメラの物だけ：録画の印、電池、テープの残り、日付と時刻（AM 2:04）。時刻のカードの代わりに、この時刻が進む。字はカメラの表示の書体（ドットゴシック16）。刷りは全編のまま（章ごとのフィルター切り替えはしない、の決まりどおり）。
- **澪の顔は入れない**：廊下で話すあいだ、桐生はカメラを胸の高さで構えたまま澪を見ている。画は澪の口元から下で切れる（証言の部屋で聞き手を「胸で切る・顎で切る・口元で切る」のと同じ文法を、澪に返す）。首を振るのは、あごと髪と毛布の動きで見える。第7章の「澪の顔が正面から見えるのは夕方の扉の一度だけ」を守る。
- 「俺でもだ」のあと、桐生はカメラを目に当てる（画が胸から目の高さへ上がる）。ここから先は、のぞいたまま歩く人になる。
- 外の光は三つだけ：カメラの小さなビデオライト（近くの雨の筋と数メートルだけ）、夏希のスマホ、稲光（林と道が一瞬だけ全部見える。ファインダーの絞りが追いつかず紙の白に飛んでから戻る）。懐中電灯は持たない（第3章「桐生さんの懐中電灯は、ここに置いたままでした」）。一灯で闇を探る画にしない：ライトは広く浅く、見えるのは雨の筋と人の上半身まで。地形は稲光で見せる。
- 手すりの小さい定点カメラ（赤いランプ）は画に入れない。桐生は定点に触れない（第6章の設計の頼み）。

## 仕掛け（この章の「型」）
### 1. 押すのはプレイヤー
- 録画の Ｅ は、押すまで進まない。押した瞬間に夏希の1秒が出て、消える。戻せない。企画書の「その指はプレイヤーの指」。
- 1秒の画：夏希が自分の部屋でカメラに向かって座っている正面（「上映用」は合宿の前に一人で撮った物）。字は「夏希：去年の夏、私と澪は——」。声が届くまでは字だけ。二度と出ない。

### 2. 同じ時間を、同じ言葉で、外から
- 廊下の台詞は ch3.txt【扉の番.二時】の行をそのまま使う（ch8.txt に写し、出どころを // に書く。第3章を直したらここも直す）。
- 扉の前は ch3.txt【扉の番.二時半】と同じ順：ノック → 桐生 → ノック → 夏希 → ノック → 桐生 → 離れる。第3章で欠けて聞こえた言葉が、外では全部聞こえる。

| 第3章（中で聞こえた） | この章（外で言っている） |
|---|---|
| 桐生：澪！　……け、……れ！ | 桐生：澪！　開けてくれ！ |
| （声）……じゃ、……なかった…… | 夏希：澪！　ここじゃ、なかった！ |
| 桐生：……開け、……澪…… | 桐生：……開けろ、澪。……開けてくれ。 |

- 第3章で「（嵐の音）」だった間に、外では二人が小声で話している（中には聞こえない）。夏希「……聞こえてるよ、たぶん」桐生「聞こえてる。……俺が、そう言ったんだ」。
- 叩くのは Ｅ。叩くたびに画が揺れる（空いた手で叩く。手は画に入らない）。3回目のあとは、押しても桐生は叩かない（「……もう、いい」）。第7章は「何度でも叩ける」、この章は「三度でやめる」。桐生は去年を知らないから、あきらめが早い。

### 3. 話し続ける監督（証言 二の聞き手の言葉と合わせる）
- 聞き手「テープの中で、桐生さんは、ずっとカメラに話しかけています。記録しておく、と」「山道で、一度だけ、名前を言いかけて、やめるんです。……『陽太の』、と」。この二つは台本にそのまま入れる。
- 三段で変わる：(1) 記録「二時、三十四分。記録しておく。」（時刻、誰がどこにいるか、これから何をするか）→ (2) 講釈（題名は一つだけ：森の中でカメラを回し続ける映画の話。夏希の好きな一本）→ (3) 独り言（誰に言っているのか分からなくなる）。
- 「陽太の、」で止まる。夏希が振り向く。桐生「……いや。カット」。口裏合わせを主導した人が、最後まで自分の台本（監督）で言葉を切る。夏希は何も言わない（彼女の言葉は第11章の5行のために取っておく。「一人じゃ無理だった」と重ねない）。

### 4. 撮ろうとして落ちる
- 曲がり角で稲光。崩れた路肩と、すき間に垂れたガードレールが一瞬だけ見える。◇「崩れた所を、撮る」。寄って下へ向けると足もとが崩れる。事故ではなく、撮り続けたこと（彼の台本）が死因（決定事項 2026-11-13）。
- 寄らずに待っても、しばらくすると桐生が自分で一歩出る（章は必ず進む）。
- 落ちる所は画が回るだけ。体は映らない。止まったあとの画は、手に握ったままのカメラが見上げる雨の空（第6章の設計「落ちたあとも、カメラを離していない」）。
- そこから先、プレイヤーにできることは無い。向きも変えられない。赤い印と時刻だけが進む。夏希が落ちる音は画の外。少しして足音が上へ遠ざかる（3時半に家へ戻る夏希）。

### 5. 目当て（◇）は監督のメモ
- この章の ◇ は澪の証言の形ではなく、桐生の短い段取りの言葉（「夏希を連れてくる」「扉を叩く」「下の道まで」「崩れた所を、撮る」）。澪＊のページ（証言の紙）は一行も出ない。誰の証言でもない時間だから。

## 決めたこと（Claude。ユーザーが変えてよい）
1. **章のカードの問いは「このテープは、ご覧になりましたか？」**。証言 一で聞き手がつまんで見せたテープを受ける。第11章の問い「あの夜のテープは、もう残っていないんですね？」と対になる（見ていないテープと、隠したテープ）。
2. **澪は口元から下だけ**（上の「画の型」）。
3. **始まりは二階の踊り場の十数秒**（桐生の目）。カメラを外した所からファインダー。「撮り始めると、その人の目がカメラになる」を一度だけ体で見せるため。
4. **題名は『ブレア・ウィッチ・プロジェクト』の一つ**。森でカメラを回し続けて、カメラに謝り、カメラが落ちて終わる映画。台詞の方針で夏希の好きな一本になっている。桐生は謝るのを朝に回し、謝らないまま、同じ終わり方をする。
5. **扉は三度でやめる**（第3章の3回に合わせる）。
6. **落ちるきっかけは「撮りに寄る」**。プレイヤーが寄らなければ、桐生が自分で寄る。
7. **終わりの雨の空は約50秒**。そのあいだに夏希の声、落ちる音、上がっていく足音。操作は無い。
8. **桐生と夏希の声は、録れるまで字だけ**。夏希の1秒「去年の夏、私と澪は——」と扉の「ここじゃ、なかった」は、夏希役が決まったら録る行に足す（足りない音とモデルの表にある）。
9. **カーラジオ**：20時からの同じ放送の繰り返し（いまある素材）を、車の中のこもった音で。地名を言う0時のニュースは流さない（夏希が言葉で伝える）。地名を言う版の録音は要らなくなる。
