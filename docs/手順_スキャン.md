# 手順：ユーザーのスキャン（Scaniverse の glb）を小道具にする

受け取ったスキャンの一覧と直すところは /mnt/project-files/スキャン/受け取ったスキャン一覧.md。元の glb はプロジェクトの uploads（作業用の写しは /home/claude/work/scan/s01〜s10.glb、作業環境が消えたら取り直す）。
できた小道具は assets/scans/ に置き、blender/shot.py の GENKAN_SCANS（名前：位置と向き）で玄関に置く（夜・夕方の両方が genkan_props4 を通る）。

## 1. 床を切り取り、穴をふさぎ、色を焼き直す（靴などの立体）

    cd blender && python3 scan_prep.py -- <in.glb> <out.glb> shoes [テクスチャ px=2048] [面の数=40000]

- 床の面を当てはめて水平にし、床より 4mm 上の面だけ残す。真ん中の大きな塊（靴なら左右の2つ）だけ残す。
- スキャンは UV の継ぎ目で切れているので、先に頂点を溶接する（しないと継ぎ目が全部「穴」になる）。
- 穴（靴の口、スキャンの抜け、床との切り口）はふさぎ、新しい UV に元の色を「選択から焼く」で写す。ふさいだ所は隣の面の色が入る。8K の地図（ほとんど床）は 2048 の1枚になる。
- 一度に3本並べて走らせるとメモリ不足で落ちる（8K の画像）。1本ずつ。

## 2. 実在のロゴ・文字を消す

    python3 scan_paint.py -- <in.glb> <out.glb> <rule>

- `red_stripes`：赤（桃色）の線を周りから塗り込む（靴2の3本線）。
- `boxes:x0,y0,x1,y1,b;...`：テクスチャの画素の箱（画像ビューアで見た左上原点）。b＝地より明るい文字、d＝暗い文字、a＝箱ごと（型押し）。
- 箱の場所は、明るさを上げたテクスチャで探す。3Dで見えている文字の場所は、プレビュー画像の画素からレイを飛ばして UV を引く（blender/scan_pick.py）。同じ文字が左右の靴で別の島に2つあることが多い。
- 書き出しは読み込んだ画像を使い回すので、塗った画像は保存して読み直してから書き出す（スクリプトでやっている）。

## 3. 平たい敷物（マット）

    python3 scan_mat.py -- <in.glb> <out.glb>

- 厚さ 4mm ほどの敷物は高さで切ると穴だらけになるので、敷物の範囲に細かい板を敷き、上から元の色と「床からの高さ」を焼く。床はちょうど高さ0なので、少しでも高い所が敷物（房も残る）。外は透明（glTF の MASK）。

## 4. 傘（透明なビニール）

    python3 scan_umbrella.py -- <scan_prep の出力.glb> <out.glb>

- Scaniverse は透明なビニールを取れず、3本がくっついた灰白色の塊になる。スキャンから残すのは、傘立て（縁の少し下まで）と柄（巻いた布の上端より上）だけ。
- 縁の高さは「高さごとの幅」が狭くなる所、柄の付け根は幅が広がる所（柄の曲がり）で見つける。そのすぐ下とすぐ上で3つの塊に分け（k-means）、組み合わせて傘ごとの軸にする。
- 軸に沿って、巻いた布（8枚のひだ、ゆるく巻いてはみ出すひだ1枚、留めバンドのくびれ）、中棒、骨、石突き、3本をまとめる輪ゴム（スキャンの高さ .47）を作る。布は半透明（BLENDED、0.38／重なったひだは 0.68。0.22 では刷りの画でほとんど見えなかった）。

## 5. 上から見て文字を描き替える（お菓子の袋）

    python3 scan_relabel.py -- top <glb> <top.png>              # 色だけの真上の画（と範囲の json）
    python3 scan_snacks_edit.py <top.png> <edit.png> <mask.png>  # 真上の画の上で消して描く
    python3 scan_relabel.py -- apply <glb> <top.png> <edit.png> <mask.png> <out.glb>

- 焼き直したテクスチャは UV の島で文字が切れているので、テクスチャの上では描けない。真上の画の上で描き、上を向いた面（法線 z > .35）にだけ、マスクの白い所を真上から投影して焼き戻す。
- 消すのは cv2.inpaint、描くのは PIL（Noto Serif/Sans CJK）。文字の向きは元の文字に合わせる（袋は裏返しや斜めに置いてある）。
- 実在の商品の文字・ロゴ・ラベルの柄を架空の物に描き替えた（記録の表）。

## 6. 黒い物の床の残りと文字（スリッパ）

    python3 scan_prep.py -- <in> <out> shoes 2048 40000 .012   # 床の板の反りで残る床を、高さ 12mm で切る
    python3 scan_dark_clean.py -- <in.glb> <out.glb>

- 低い所の床の色の面を消し、まわりの布より明るい灰色（印刷された名前）を周りの黒で塗る。底のふちにぎざぎざが少し残る（黒いので目立たない）。

## 7. マグの飲み残し

    python3 scan_mugs.py -- <glb> <out.glb>

- 内側の底に穴があり、上から見ると透ける。口の円を当てはめ（取っ手は口より低いので入らない）、その中心に飲み残しの円板を置いてふさぐ。白いマグにコーヒー、緑のマグにほうじ茶。

## 置き場所（blender/shot.py の GENKAN_SCANS と MORE_SCANS）
- 玄関の土間：靴3足（つま先を戸口へ）。西の隅：傘立て。上がり框の上のマット：スリッパ（つま先を家の中へ）。廊下の東の壁際：リュック。
- 居間には家具がなく、どちらの場面でも見えないので、マグとお菓子は階段の2段目（撮影隊の休憩の跡、夜も残る）、梱包テープは3段目。
- 夏希（夕方）が持つ布テープは shot.tape_roll（芯と穴のある巻き。床の印の黄色い布テープと同じ色）。茶色の梱包テープのスキャンは寸法（直径 9.8cm）だけ使い、階段に置く方を shot.tape_roll で作った（琥珀色、外側の1巻きは半透明）。
