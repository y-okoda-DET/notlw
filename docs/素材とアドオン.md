- 元の画像は assets/tex/ph/ に 2K の jpg で置いている（`<名前>_<種類>.jpg`）。ダウンロード元：`https://dl.polyhaven.org/file/ph-assets/Textures/jpg/2k/<名前>/<名前>_<種類>_2k.jpg`。
- ambientCG の物は名前の頭に acg_ を付けて同じフォルダに置く。ダウンロード：`https://ambientcg.com/get?file=<ID>_2K-JPG.zip`（中身は acg-download.struffelproductions.com から配られる）。ambientCG もすべて CC0（https://docs.ambientcg.com/license/）。
- Poly Haven の素材はすべて CC0（著作権を放棄。商用可、改変可、クレジット不要、再配布可）。https://polyhaven.com/license
- ゲームに入る画像は、これらから blender/exterior.py・trees.py が numpy で作る（壁ごとの汚れ・はがれ・雨だれ、一枚ずつのスレート、スギの葉の房は自前で描いている）。
- 試しに落として使わなかったもの（weathered_planks・moss_wood・bark_brown_01・bark_willow）はリポジトリに入れていない。

## アドオン

- いまは使っていない。木（スギ）は Sapling Tree Gen を使わず、blender/trees.py で自前に組んだ（枝打ちされた幹、上半分だけの細い樹冠、房になった葉、木ごとの高さ・太さ・傾き・梢の折れ。Sapling の葉は平たい板で、スギの房の形を出しにくいため）。
- 作業環境の接続：dl.polyhaven.org・extensions.blender.org はつながる。api.polyhaven.com・ambientcg.com・www.ambientcg.com・acg-download.struffelproductions.com・acg-media.struffelproductions.com も、ユーザーが許可に足して、つながるようになった（2026-10-31）。
