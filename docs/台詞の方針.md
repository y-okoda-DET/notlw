# 台詞の方針

2026-11-02 ユーザーの指示「台詞、各キャラクターに一定の個性があるように。あと、映画関係の固有名詞を頻出させたい。作品名は『』で表記。方針忘れないようにして」。台詞を書く・直すときは、毎回この文書に照らす。

## 全体の約束
- **一人ひとりに一定の個性**：名前を隠しても誰の台詞か分かること。語尾、文の長さ、呼び方、よく使う言葉を下の表で固定する。
- **映画の固有名詞を頻出させる**：作品名・監督名・役名・用語（「ファイナルガール」など）を、ほぼ全ての会話に一つ以上入れる。サークルの日常語として自然に出す（説明しない、知らない人を置いていく）。
- **映画の題名は、いまより抑える（2026-11-13 夜、ユーザー「映画の題名の連打、いまより抑えようか」。別のレビュアー2人が「作為に聞こえる」と指摘）**：下の「ほぼ全ての会話に一つ以上」はやめる。題名を出すのは桐生が中心で、一場面に一つまで。ほかの人は第1章で少しだけ。20時からは桐生だけ。澪の証言（地の文）と、3時半の夏希には入れない。いまの台本は、次に台本を触るときにこの方針で減らす（入口の E）。
- **夜が深まるほど引用を減らす（2026-11-13、ユーザー OK）**：映画の固有名詞は、第1章と20時までは今までどおり、ほぼ全ての会話に入れる。21時から少しずつ減らし、0時を過ぎたら桐生だけが引用し続ける（ほかの人は引かない。澪の証言の地の文も同じ）。本気で怖がっている場面（23時の扉、第4章）で引用すると映画談義に聞こえるため。引用が消えていくこと自体で、信じ込みが深まる様子を見せる。桐生が最後まで引くのは、彼の台本が「ルールを知る者」だから。下の「確かめ方」の「固有名詞が一つ以上」は、20時までの会話と桐生の台詞に当てる。
- **作品名は『』**：『ハロウィン』『スクリーム』。監督名・役名はそのまま（カーペンター、ローリー・ストロード）。邦題があるものは邦題で書く。
- 固有名詞の出し方も人物ごとに違える（下の表）。誰が何を引くかで、その人の「感染した台本」（企画書「登場人物と感染した台本」）がにじむようにする。
- 実在の作品は、題名・監督・有名な場面への言及までにする。台詞や筋を長く引き写さない。
- 書き起こしの記法（（沈黙・○秒）、……、（雨の音）など）はこれまでどおり。

## 確かめ方
- 台詞を直したら、場面ごとに「名前を伏せて誰か分かるか」「その会話に固有名詞が一つ以上あるか」「作品名が『』か」を見る。
- 台本（場面ごとの台詞の一覧）を作るときは、この文書へのリンクを先頭に置く。
